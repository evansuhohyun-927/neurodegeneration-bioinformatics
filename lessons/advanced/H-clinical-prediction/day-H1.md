## 개념 설명

### 세 가지 예측 문제: 지금, 나중, 그리고 아직 아닌

5주차의 PD 분류는 "이미 진단받은 사람과 건강한 사람을 센서 값으로 구분할 수 있는가"였습니다. 임상 예측 연구에서는 이 질문을 더 정확히 나눕니다.

- **진단 모델(diagnostic model):** 예측 시점에 **이미 존재하는** 상태를 맞힙니다. "지금 이 사람이 PD인가?" 정답은 같은 시점의 기준 검사(reference standard)로 정합니다.
- **예후 모델(prognostic model):** 예측 시점 **이후에** 일어날 사건을 맞힙니다. "진단받은 이 사람이 5년 안에 낙상하거나 치매로 진행할까?" 정답은 추적 관찰로 얻습니다.
- **조기진단·전구기 모델:** 진단 기준을 아직 만족하지 않는 사람이 **앞으로** 질환이 드러날지(phenoconversion) 예측합니다. 형식은 예후 모델에 가깝지만, 결과가 "질환 발병"이라 진단의 언어로 오해되기 쉽습니다.

PD에서 전구기는 실제 연구 주제입니다. 국제 운동장애학회(MDS)는 위험 인자와 전구 징후(예: REM 수면 행동장애, 후각 저하 등)를 결합해 "전구기 PD일 확률"을 추정하는 연구용 기준을 제시했고(Berg 등 2015, Heinzel 등 2019 개정), 특발성 REM 수면 행동장애 다기관 코호트에서는 시간이 지나며 상당수가 파킨슨증이나 치매로 진행한다는 보고가 있습니다(Postuma 등 2019). 이런 자료가 **연구용 위험 추정**이지 개인 진단 도구가 아니라는 점이 오늘 레슨 전체의 전제입니다.

### 문제 정의 카드: 네 칸을 먼저 채운다

모델을 만들기 전에 다음 네 칸을 문장으로 씁니다. 이 칸이 비어 있으면 성능 숫자는 해석할 수 없습니다.

1. **대상 집단:** 모델을 실제로 쓸 사람들. "운동장애 클리닉에 처음 의뢰된 50세 이상", "REM 수면 행동장애로 진단받은 미발병자"처럼 구체적으로.
2. **예측 시점(prediction time):** 어떤 정보까지 쓸 수 있는가. 초진 당일? 첫 6개월 추적 후? 이 시점 이후의 정보는 특징에 들어갈 수 없습니다([Day E6](../E-ehr/day-E6.md)의 시간 누수).
3. **결과와 기준 검사:** 무엇을 맞히는가, 정답은 무엇으로 정하는가. 임상 진단, 영상, 병리, 장기 추적 후 확정 등. 기준 검사 자체도 완벽하지 않으며(예: 초기 임상 진단은 나중에 바뀔 수 있음), 일부 사람만 기준 검사를 받으면 **검증 편향(verification bias)** 이 생깁니다.
4. **쓰임새:** 결과로 무엇을 하는가. "양성이면 정밀 검사 의뢰"처럼 행동과 연결해 적어야 H3–H4의 임계값과 임상적 유용성을 정할 수 있습니다.

비유하면, 이 카드는 실험 프로토콜의 "재료와 방법" 첫 단락입니다. 그 단락 없이 결과 그림만 있는 논문을 믿지 않듯, 이 카드 없는 AUC도 믿지 않습니다.

### 스펙트럼 편향: 쉬운 문제를 풀고 어려운 문제를 풀었다고 말하기

환자-대조군 설계는 "진단이 확실한 중등도 환자"와 "아주 건강한 자원자"를 모으기 쉽습니다. 두 집단은 거의 무엇으로든 구분됩니다. 그런데 실제 진료실에 오는 사람은 증상이 애매한 초기 환자, 그리고 떨림·느린 움직임을 보이지만 다른 질환인 사람(감별 대상, mimics)입니다. 이 차이 때문에 연구에서의 성능이 실제 쓰임새에서 재현되지 않는 현상을 **스펙트럼 편향**이라 합니다(Ransohoff & Feinstein 1978). 예시 2가 이것을 숫자로 보여 줍니다. 전구기 예측은 가장 어려운 쪽 끝입니다. 신호가 가장 약할 때 맞혀야 하기 때문입니다.

### 유병률이 바뀌면 PPV가 바뀐다

민감도와 특이도는 (스펙트럼이 같다면) 집단이 바뀌어도 비교적 안정적이지만, **PPV와 NPV는 유병률에 직접 의존**합니다. 환자-대조군 연구는 유병률을 인위적으로 50% 근처로 만들기 때문에, 거기서 계산한 PPV를 일반 인구 선별에 그대로 옮기면 크게 과장됩니다. 실제로는 스펙트럼까지 함께 바뀌어 민감도·특이도도 유병률과 같이 움직일 수 있다는 보고도 있습니다(Leeflang 등 2013). 그래서 "이 도구의 PPV는 90%"라는 문장에는 항상 "어느 집단에서"가 붙어야 합니다.

## 예시로 이해하기

### 예시 1 — 같은 도구, 세 가지 유병률

민감도 85%, 특이도 90%인 가상의 선별 도구를 1만 명에게 쓴다고 합시다.

```python
import numpy as np
import pandas as pd

sens, spec = 0.85, 0.90          # 가상의 선별 도구: 민감도 85%, 특이도 90%
rows = []
for setting, prev in [("환자-대조군 연구(1:1)", 0.50),
                      ("고위험 의뢰 클리닉", 0.10),
                      ("일반 인구 선별", 0.005)]:
    n = 10000
    diseased = n * prev
    tp = sens * diseased
    fp = (1 - spec) * (n - diseased)
    fn = diseased - tp
    tn = (n - diseased) - fp
    rows.append({"상황": setting, "유병률": prev, "양성 판정": round(tp + fp),
                 "진양성": round(tp), "위양성": round(fp),
                 "PPV": round(tp / (tp + fp), 3), "NPV": round(tn / (tn + fn), 4)})
print(pd.DataFrame(rows).to_string(index=False))
```

출력:

```text
            상황   유병률  양성 판정  진양성  위양성   PPV    NPV
환자-대조군 연구(1:1) 0.500   4750 4250  500 0.895 0.8571
    고위험 의뢰 클리닉 0.100   1750  850  900 0.486 0.9818
      일반 인구 선별 0.005   1037   42  995 0.041 0.9992
```

도구는 그대로인데 PPV가 0.895에서 0.041로 떨어졌습니다. 일반 인구 선별에서는 양성 판정 1,037명 중 실제 환자는 42명뿐입니다. 반대로 NPV는 0.9992로 매우 높습니다. 이런 상황에서 선별 도구가 할 수 있는 일은 "양성이면 진단"이 아니라 "음성이면 당분간 안심, 양성이면 다음 단계 검사"입니다. 쓰임새(네 번째 칸)가 숫자 해석을 바꿉니다.

### 예시 2 — 스펙트럼 편향을 만들어 보기

질환 진행 정도(0–1)에 따라 오르는 가상 지표 하나로, 누구와 누구를 비교하느냐에 따라 AUC가 어떻게 달라지는지 봅니다.

```python
import numpy as np
from sklearn.metrics import roc_auc_score

rng = np.random.default_rng(1)
# 가상의 혈액·센서 지표 하나. 질환이 진행할수록(severity 0→1) 지표가 오른다.
def marker(severity, n):
    return 2.0 * severity + rng.normal(0, 1, n)

n = 400
established = marker(rng.uniform(0.7, 1.0, n), n)   # 진단이 확정된 중등도 이상 환자
prodromal   = marker(rng.uniform(0.0, 0.4, n), n)   # 아직 진단 전, 전구기
healthy     = marker(np.zeros(n), n)                # 건강한 자원자
mimics      = marker(np.full(n, 0.5), n)            # 비슷한 증상을 보이는 다른 질환

def auc(pos, neg):
    y = np.r_[np.ones(len(pos)), np.zeros(len(neg))]
    return roc_auc_score(y, np.r_[pos, neg])

print(f"확정 환자 vs 건강 자원자       AUC {auc(established, healthy):.3f}")
print(f"확정 환자 vs 감별 대상 질환     AUC {auc(established, mimics):.3f}")
print(f"전구기 vs 건강 자원자           AUC {auc(prodromal, healthy):.3f}")
print(f"전구기 vs (건강 + 감별 대상)    AUC {auc(prodromal, np.r_[healthy, mimics]):.3f}")
```

출력:

```text
확정 환자 vs 건강 자원자       AUC 0.859
확정 환자 vs 감별 대상 질환     AUC 0.667
전구기 vs 건강 자원자           AUC 0.598
전구기 vs (건강 + 감별 대상)    AUC 0.474
```

지표와 측정 잡음은 모두 같습니다. 바뀐 것은 **비교하는 사람들**뿐입니다. 확정 환자 vs 건강 자원자의 AUC 0.86은 논문 초록에 쓰기 좋은 숫자지만, 전구기 사람을 건강인과 감별 대상 질환 사이에서 골라내야 하는 실제 문제에서는 0.47로 우연 수준입니다(감별 대상의 지표가 전구기보다 오히려 높게 설정되었기 때문). 이 가상 예시의 숫자 자체는 의미가 없고, **설계가 숫자를 만든다**는 구조가 핵심입니다.

### 예시 3 — 문제 정의 카드 채우기

5주차 PD 분류 과제를 카드로 다시 쓰면 다음과 같습니다. 왼쪽 열은 5주차의 실제 설정, 오른쪽 열은 "조기 선별"이라고 부르려면 필요했을 설정입니다.

| 칸 | 5주차 과제(실제) | 조기 선별이라고 말하려면 |
|---|---|---|
| 대상 집단 | 공개 데이터에 모인 PD 환자와 대조군 | 아직 진단받지 않은 위험군(예: 고령, 전구 징후 보유자) |
| 예측 시점 | 진단 이후 측정한 한 번의 기록 | 진단 **이전**의 기준 시점 측정 |
| 결과·기준 검사 | 데이터에 기록된 진단 라벨 | 추적 기간 중 임상 진단 기준을 만족(발병) |
| 쓰임새 | 탐색적 분류 baseline | 양성이면 전문의 평가 의뢰 등, 행동과 연결 |

왼쪽 설정으로 얻은 성능은 "이미 진단된 사람을 구분하는 baseline"입니다. 오른쪽 문장을 쓰려면 오른쪽 설계의 데이터가 필요합니다.

⚠️ **흔한 오류 1 — 유병률을 0이나 1로 넣었다**
`prev = 0`이면 `tp + fp`가 위양성만 남고, `prev = 1`이면 NPV 계산에서 0으로 나눕니다. 유병률은 0과 1 사이의 값으로 넣습니다.

⚠️ **흔한 오류 2 — 환자-대조군 자료로 계산한 PPV를 보고서에 그대로 쓴다**
표본의 유병률은 연구자가 정한 숫자입니다. PPV를 쓰려면 목표 집단의 유병률을 따로 밝히고 예시 1처럼 다시 계산한 값을 함께 씁니다.

③ 같은 사람이 훈련과 시험에 모두 들어간다
④ 예측 확률이 실제 비율과 맞지 않는다

<details><summary>정답 보기</summary>

②. ③은 데이터 누수(Day 33), ④는 보정 문제(H3), ①은 불확실성 문제입니다. 스펙트럼 편향은 "누구를 모았는가"의 문제입니다.

</details>

**4.** (단답) 예측 시점을 "초진 당일"로 정했다면, 6개월 뒤 방문에서 잰 센서 값을 특징으로 써도 될까요?

<details><summary>정답 보기</summary>

안 됩니다. 예측 시점 이후의 정보라서 실제 사용 상황에서는 존재하지 않습니다. 쓰고 싶다면 예측 시점을 "6개월 추적 후"로 다시 정의해야 하고, 그러면 대상 집단도 6개월 동안 추적된 사람으로 바뀝니다.

</details>

**5.** (객관식) 전구기 PD 위험을 추정하는 연구용 기준에 대한 설명으로 가장 적절한 것은?
① 개인에게 확정 진단을 내리는 도구다
② 여러 위험 인자와 전구 징후를 결합해 연구 목적의 확률을 추정하는 틀이다
③ 유병률과 상관없이 PPV가 일정하다
④ 기준 검사가 필요 없다

<details><summary>정답 보기</summary>

②. MDS 연구용 기준은 연구 대상 선정과 위험 추정을 위한 틀입니다. 확률 추정이므로 대상 집단의 사전 확률에 따라 해석이 달라지고, 결과(발병)는 추적으로 확인해야 합니다.

</details>
