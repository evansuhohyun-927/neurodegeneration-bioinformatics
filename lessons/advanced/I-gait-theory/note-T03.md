## 본문

### 1. 입력 1 — 인체계측: 질량, 질량중심, 관성모멘트
역동역학에는 분절마다 질량 m, 질량중심(COM) 위치, COM 기준 관성모멘트 I가 필요합니다. 사람에게서 직접 잴 수 없으므로 사체·영상 연구에서 얻은 비율을 체질량과 분절 길이에 곱합니다([RM] 3장 pp.63–78, [Wi] 4장 pp.67–88).

- 분절 질량 m = P × 체질량, COM = 근위단 + R × (원위단 − 근위단), 회전반경 ρ = K × 분절 길이, I₀ = m·ρ²
- **평행축 정리**: 다른 축에 대한 관성모멘트 I = I₀ + m·d² (d = COM에서 그 축까지 거리). COM을 지나는 축에서 가장 작습니다.

예를 들어 [Wi] Table 4.1의 다리(leg) 값(질량비 0.0465, COM 근위에서 0.433, 회전반경 0.302)을 체질량 70 kg, 다리 길이 0.40 m에 쓰면 m = 3.26 kg, I₀ = 0.0476 kg·m², 무릎 축 I = 0.145 kg·m²입니다(이 노트를 위해 계산한 예).

비율표는 **끝점 정의와 한 쌍**입니다. 대퇴 COM 비율이 Dempster 표에서는 0.433, Chandler 표에서는 0.372인 것은 사람이 달라서가 아니라 끝점(고관절 중심 vs 대전자)이 달라서 생기는 차이가 큽니다([RM] 3장). 마커 위치가 표의 지표와 다르면 그대로 쓸 수 없고, 아동·비만·절단자·보조기 착용자에게는 평균 성인 비율이 맞지 않습니다. 외골격이나 보조기를 달면 분절 관성 자체가 바뀝니다.

### 2. link-segment 모델과 자유물체도
[Wi] 5.0(p.90)의 가정: ① 분절 질량은 COM 한 점에 있다, ② COM 위치는 분절 안에서 고정, ③ 관절은 경첩(또는 구관절), ④ 관성모멘트는 일정, ⑤ 분절 길이는 일정. 분절에 작용하는 힘은 중력(COM에서 m·g), 외력(지면반력을 COP 한 점의 벡터로 대표), 그리고 관절을 건너는 근육·인대·접촉력입니다. 마지막 묶음은 미지수가 너무 많아(부정정) 관절 중심의 **알짜 힘 하나 + 알짜 모멘트 하나**로 합칩니다([RM] 5장 pp.110–114).

평면 분절 하나의 세 식(X 앞+, Y 위+, 반시계 +, 원위단 힘·모멘트는 "분절이 받는 것"으로 정의):

```
ΣFx = m·ax      →  Rxp + Rxd = m·ax
ΣFy = m·ay      →  Ryp + Ryd − m·g = m·ay
ΣM(COM) = I₀·α  →  Mp + Md + (rp − rcom) × Rp + (rd − rcom) × Rd = I₀·α
2D 외적: r × F = rx·Fy − ry·Fx
```

단위: 힘 N, 모멘트 N·m, 가속도 m/s², 각가속도 rad/s², 관성모멘트 kg·m². 분절당 식이 셋뿐이므로 미지수가 셋인 말단 분절(발)에서 시작해, 구한 근위단 반력·모멘트의 **부호를 바꿔** 다음 분절의 원위단에 넣습니다(Newton 제3법칙). swing에서는 지면반력만 0으로 두면 절차가 같습니다. [RM] 5장(p.118)이 강조하는 흔한 실수: **x 방향 힘의 모멘트 팔은 y 방향 거리**, y 방향 힘의 모멘트 팔은 x 방향 거리입니다.

아래 코드는 이 노트를 위해 만든 정적 예입니다. 70 kg인 사람이 한 발로 가만히 서 있고, COP가 발목보다 5 cm 앞에 있습니다.

```python
import numpy as np
g = 9.81
# 가상 예: 체질량 70 kg인 사람이 오른쪽을 보고 한 발로 가만히 서 있다 (X 앞+, Y 위+, 반시계 +)
M_body, m_foot = 70.0, 1.0
ankle = np.array([0.00, 0.08])      # 발목 관절 중심 (m)
com_f = np.array([0.03, 0.05])      # 발 질량중심
cop   = np.array([0.05, 0.00])      # 압력중심
F_grf = np.array([0.0, M_body * g]) # 정적이므로 지면반력 = 체중
a, alpha, I_f = np.zeros(2), 0.0, 0.004   # 가속도 0 (정적)

def cross2(r, F):                    # 2D 외적의 z 성분
    return r[0]*F[1] - r[1]*F[0]

# 발의 자유물체도: 원위단 = 지면반력(COP), 근위단 = 발목의 반력 R과 모멘트 M (미지수)
R = m_foot*a - F_grf + np.array([0.0, m_foot*g])          # ΣF = m a
M = I_f*alpha - cross2(cop - com_f, F_grf) - cross2(ankle - com_f, R)   # ΣM(COM 기준) = I α
print("발목 반력 R (N):", np.round(R, 1))
print("발목 내부 모멘트 M (N·m):", round(M, 1), "← 음수 = 시계 방향 = 족저굴곡근 모멘트")
print("단순 벡터법(지면반력 × 발목까지 수평거리):", round(F_grf[1]*(cop[0]-ankle[0]), 1), "N·m (외부 배측굴곡 모멘트)")

# 관절 파워 P = M·ω 의 부호 (W)
for name, Mj, w in [("push-off 발목", -80.0, -3.0), ("LR 무릎", 30.0, -2.0), ("TSt 발목", -60.0, 1.0)]:
    print(f"{name:10s} M={Mj:+6.1f} N·m, ω={w:+4.1f} rad/s → P={Mj*w:+7.1f} W")
```

과정 환경(Python 3.12, numpy 2.5)에서 실행한 출력:

```
발목 반력 R (N): [   0.  -676.9]
발목 내부 모멘트 M (N·m): -34.0 ← 음수 = 시계 방향 = 족저굴곡근 모멘트
단순 벡터법(지면반력 × 발목까지 수평거리): 34.3 N·m (외부 배측굴곡 모멘트)
push-off 발목 M= -80.0 N·m, ω=-3.0 rad/s → P= +240.0 W
LR 무릎      M= +30.0 N·m, ω=-2.0 rad/s → P=  -60.0 W
TSt 발목     M= -60.0 N·m, ω=+1.0 rad/s → P=  -60.0 W
```

발목 반력이 −677 N(발목이 발을 아래로 누름)이고, 내부 모멘트는 족저굴곡근 쪽입니다. COP가 발목 앞에 있으면 종아리 근육이 버텨야 한다는 직관과 맞습니다. 단순 벡터법의 34.3 N·m와 0.3 N·m 차이는 발 무게가 만든 몫입니다. 정적이고 발이 가벼우니 거의 같지만, 고관절로 올라가거나 swing처럼 가속이 큰 구간에서는 이 차이가 커집니다(5절).

### 3. 입력 2 — 지면반력: Σm(a + g)
지면반력은 모든 분절의 (질량 × (가속도 + g))의 합입니다([Wi] 5.2 식 5.7–5.8, p.101).

```
Fx = Σ mᵢ·axᵢ          Fy = Σ mᵢ·(ayᵢ + g)
```

가만히 서 있으면 체중과 같고, 몸 전체 COM이 위로 가속하면 체중보다 커집니다. 한 팔이 위로, 다른 팔이 아래로 가속하면 상쇄되므로 **지면반력만으로는 개별 분절이 무엇을 하는지 알 수 없습니다**(p.102).

**수직 성분의 두 봉우리.** Perry는 F1(LR 끝 봉우리), F2(MSt 골짜기), F3(TSt 봉우리)로 부르며, 82 m/min에서 봉우리 각 약 110 % BW, 골짜기 약 80 % BW입니다([P] 22장 Vertical Load). F1은 체중이 급히 실리며 COM의 아래로 향하던 속도를 위로 되돌리는 시기, F2는 COM이 다리 위로 올라가며 위쪽 가속이 줄어드는 시기, F3은 앞으로 떨어지는 몸을 감속하는 시기입니다([W] 2장 p.34). 느리게 걸으면(60 m/min) 수직 가속이 줄어 봉우리가 낮아지고 거의 평평한 plateau가 됩니다. 이중 봉우리의 크기는 속도에 크게 좌우되므로, 장애가 심한 사람에게는 수직 하중보다 보행 속도와 single limb stance 시간이 더 나은 기능 지표라고 Perry는 권합니다([P] 22장).

IC 직후의 짧은 충격(heel strike transient)은 F1과 다른 사건입니다. 체중의 50–125 %, 1–2 % GC 동안 지속되며([P] 22장), 응답이 빠른 장비라야 보입니다(Whittle의 예시 그림은 1000 Hz 무필터, [W] 2장 pp.35–36). 신발 속 센서를 100 Hz로 기록한 자료(I4의 gaitpdb)에서는 한두 표본에 불과해 거의 보이지 않을 수 있습니다.

**전후 성분과 부호 기준.** 지면이 발에 주는 힘(GRF) 기준으로 stance 전반은 뒤쪽(제동), 후반은 앞쪽(추진)입니다. Perry 22장은 "발이 바닥에 가하는 힘" 기준으로 써서 방향이 반대로 적힙니다(LR 끝 전방 약 13 % BW, TSt 끝 후방 23 % BW). 문헌을 옮길 때 어느 쪽 기준인지 확인합니다.

### 4. COP와 COM은 다른 것
COP는 지면반력 벡터의 작용점입니다. 발바닥 전체에 퍼진 압력의 평균 위치일 뿐이라, MSt에 뒤꿈치와 앞발이 하중을 나누면 아무것도 닿지 않은 아치 아래에 찍힐 수도 있습니다. COP는 가장 압력이 큰 곳이 아닙니다([P] 22장 Center of Pressure, [W] 2장 p.35). 수직력이 체중의 약 2 %보다 작을 때(heel contact 직후, toe-off 직전)의 COP는 작은 오차가 크게 부풀려지므로 믿지 않습니다([Wi] p.100).

COM은 분절 COM들의 질량 가중 평균인 **운동학적 양**이고, COP는 발 위치와 발목 근육 조절로 정해지는 **운동역학적·제어적 양**입니다([Wi] 5.2.5). [R] 11장에는 "COP가 COM의 수직 투영"이라는 문장이 있는데, 이는 틀린 설명입니다. 서 있을 때조차 COP는 COM을 앞뒤로 넘나들어야 COM을 되돌릴 수 있습니다. COM과 COP의 관계, 역진자 식, 보행 시작·정지는 T07에서 자세히 봅니다.

### 5. 내부 모멘트와 외부 모멘트: 같은 사건을 반대에서 본다
역동역학으로 구한 알짜 모멘트는 근육·인대 등 몸 안의 조직이 내는 **내부(internal) 모멘트**입니다. 지면반력이 관절에 만드는 **외부(external) 모멘트**는 크기가 같고 부호가 반대입니다([RM] 7장 pp.163–164). "external knee flexion moment"는 "internal knee extensor moment"와 같은 말입니다.

- **Perry — demand → response.** GRF 벡터가 관절의 어느 쪽을 지나는지로 그 순간의 자세 요구(외부 모멘트)를 읽고, 그것을 버티는 근육·인대의 반응(내부 모멘트)을 찾습니다. 벡터가 굽은 무릎 뒤를 지나면 "굴곡 요구" → 대퇴사두근의 "신전 반응"입니다([P] 22장 Moments, 3장 Upright Stability).
- **Whittle — 벡터 투영법은 근사.** 직관에 좋지만 관절 아래 분절의 질량(고관절에서 큼)과 분절 가속(swing에서 큼)을 무시합니다. 책의 그래프 자체는 역동역학으로 계산한 **내부 모멘트**입니다([W] 2장 p.25, 1장 p.11).
- **Winter — 내부 모멘트 + support moment.** 세 관절의 신전 모멘트 합 Ms = Mh + Mk + Ma(세 관절 모두 신전 +로 맞춘 경우)는 관절 하나하나보다 걸음 간 변동이 훨씬 작고, 단하지지기 내내 양수입니다([Wi] 5.2.4 p.107, 11.1 pp.236–239). Hof(2000)는 ½Mh + Mk + ½Ma를 제안했습니다([W] 2장 p.36). Perry에는 support moment 개념이 없습니다.

단순 벡터법과 역동역학의 차이는 발목에서는 거의 없고, 고관절·무릎에서는 LR 시작에 약 20 % 수준까지 날 수 있다는 보고가 있습니다([P] 22장).

| 시기 | GRF 벡터 위치 (Perry) | 외부 모멘트(요구) | 내부 모멘트(반응) |
|---|---|---|---|
| LR | 고관절 앞, 무릎 뒤, 발목 뒤 | 고관절 굴곡, 무릎 굴곡, 발목 족저굴곡 | 고관절 신전근, 무릎 신전근(vastii), 발목 배측굴곡근(pretibial) |
| MSt 끝 | 고관절 뒤, 무릎·발목 앞 | 고관절 신전, 무릎 신전, 발목 배측굴곡 | 고관절은 앞쪽 인대가 수동으로, 발목은 족저굴곡근 |
| TSt | 고관절 뒤, 무릎 앞, 발목 앞 최대 | 고관절 신전, 무릎 신전, 큰 발목 배측굴곡 | 고관절·무릎은 정렬과 인대로 수동 안정, 발목은 족저굴곡근이 능동 제동 |

(벡터 위치: [P] 3장 Upright Stability. 표는 이 노트를 위해 새로 짠 것입니다.)

[RM] 5장(p.126)은 그래프 표시 관례를 하나 더 알려 줍니다. 신전(발목은 족저굴곡) 모멘트를 +로 그리는 것이 관례인데, 오른쪽을 보고 걷는 사람의 반시계 + 규칙으로 계산하면 고관절 굴곡·발목 배측굴곡 모멘트가 +로 나옵니다. 그래서 고관절과 발목은 계산값에 −1을 곱해 그립니다. **계산 부호와 그래프 부호가 다를 수 있으니, 그래프 축에 방향 이름을 적습니다.** 3D에서는 모멘트를 근위 분절, 원위 분절, JCS, 진행면 중 어느 좌표계로 분해했는지도 적어야 합니다. 같은 자료라도 분해 좌표계에 따라 군 차이의 유의성이 달라진 사례가 있고, JCS 성분은 벡터가 아니므로 더해서 support moment를 만들 수 없습니다([RM] 7장 pp.164–167).

정규화 단위: 모멘트 N·m/kg, 파워 W/kg(Perry는 체중·키로 나눈 N·m/kg·m를 씀, [P] 22장).

### 6. joint power: 부호의 규칙과 그 예외
관절 파워는 알짜 관절 모멘트와 관절 각속도의 곱입니다([Wi] 6.0.6 식 6.1, [RM] 6장 p.141).

```
P = M · ω            (W = N·m × rad/s)
W = ∫ P dt           (J, 부호가 바뀌는 지점마다 끊어 양·음을 따로 적분)
```

M과 ω가 같은 방향이면 P > 0(생성, 근건 단위가 분절에 에너지를 줌), 반대면 P < 0(흡수)입니다. 부호 규약을 어떻게 잡아도 이 규칙은 그대로입니다. 단 ω는 반드시 **관절** 각속도(두 분절 각속도의 차)여야 하고, 안전한 쓰기는 P = (원위 분절에 작용하는 모멘트) × (ω_원위 − ω_근위)입니다([RM] 6장 p.144의 주의). 위 코드의 세 예에서 push-off 발목은 생성(+240 W), LR 무릎과 TSt 발목은 흡수(−60 W)입니다.

[Wi] 7.4.6(pp.168–170)은 정상 보행의 봉우리에 이름을 붙입니다. 발목: A1(흡수, 경골 전진 제어) → A2(생성, push-off, 보행 중 최대). 무릎: K1(LR 흡수) → K2(작은 생성) → K3(toe-off 전후 흡수) → K4(swing 끝 hamstrings 흡수). 고관절: H1(stance 초 신전근 생성) → H2(흡수) → H3(굴곡근이 넙다리를 끌어올리는 생성). 크기 감각: Perry 자료의 PSw 발목 생성은 3.7 W/kg·m(54 % GC, [P] 4장 Forces), Winter 부록 피험자에서는 약 270 W(4.8 W/kg, 52 % stride, 부록 자료로 이 코스에서 계산).

**부호를 근수축 형태로 바로 바꾸면 안 되는 이유**
1. **수동 조직도 모멘트와 파워를 낸다.** TSt 내내 커지는 고관절 굴곡 모멘트는 굴곡근이 조용한 동안 앞쪽 인대의 수동 장력이 냅니다. PSw의 외전 모멘트는 fascia lata의 수동 장력, PSw 무릎 40° 굴곡은 발목 파워에 대한 원격 반응입니다([P] 22장 Functional Significance).
2. **근섬유와 힘줄은 따로 움직인다.** PSw 발목 파워는 근섬유 단축이 아니라 건의 탄성 반동이라는 것이 Perry 2판의 결론입니다(T01, T04).
3. **동시수축은 보이지 않는다.** 알짜 40 N·m, ω = 3 rad/s면 120 W로 계산되지만, 실제로 작용근 50, 길항근 10 N·m였다면 생성 150 W와 흡수 30 W가 동시에 일어난 것입니다([Wi] 6.3).
4. **모멘트는 전달도 한다.** 두 분절이 같은 방향으로 돌 때 모멘트는 생성·흡수와 함께 한 분절에서 다른 분절로 에너지를 넘깁니다. 관절 힘은 에너지를 전달만 하고, 몸 전체 에너지를 바꾸는 것은 모멘트뿐입니다([RM] 6장 pp.142–146).

그래서 Perry는 양(+)을 "흔히 구심성", 음(−)을 "흔히 원심성"이라고만 하고, 특정 근육의 활동은 EMG로 확인하라고 합니다. 이 노트는 파워 부호를 "근건 단위(와 수동 조직)가 에너지를 내는가 흡수하는가"로 읽기를 권합니다. 각속도·모멘트·파워 세 곡선을 세로로 나란히 그리는 것이 표준 제시법입니다([RM] 6장 그림 6.6).

### 7. 관절 반력은 관절면 접촉력이 아니다
자유물체도에 그리는 관절 반력은 "분절을 가속시키는 순 힘"입니다. [Wi] 5.0의 예를 숫자를 바꿔 다시 쓰면: 아래 분절 무게가 100 N이고 근육이 쉰 채 수동 조직이 매달고 있으면 관절면 압축은 0, 반력은 100 N입니다. 근육이 합쳐 160 N으로 당기면 관절면 압축은 60 N이 되지만 반력은 여전히 100 N입니다. 가만히 선 사람이 다리 근육에 힘을 꽉 주어도 알짜 힘과 알짜 모멘트는 변하지 않습니다(근육 장력 증가와 뼈 압박 증가가 상쇄, [RM] 5장 pp.120–121). 관절면 하중을 알려면 개별 근력을 알아야 하는데, 그것은 부정정 문제입니다. 중거리 달리기 stance의 발목 압축력이 체중의 11배를 넘고 그중 지면반력의 몫은 약 1/5뿐이라는 추정이 있습니다([Wi] 5.3 p.114). 근력 분배(정적 최적화)는 T04에서 다룹니다.

역동역학의 또 다른 한계([RM] 5장 pp.121–122): 발·몸통은 강체 가정이 약하다, 이관절근이 관절별 계산에 섞인다, 입력(지면반력, COP, 마커, 관성값, 관절 중심, 가속도) 오차에 민감하다(COP 1 cm 오차 × 700 N = 7 N·m), 연구 간 모멘트 비교에는 적어도 10 %의 여유를 둔다. stance는 지면반력이 지배하므로 지면반력만 정확하면 대체로 괜찮고, swing은 필터와 인체계측 추정이 결정적입니다.

### 8. 외골격·보조기·의지: 닫힌 사슬
보조기가 하퇴와 대퇴에 단단히 고정되어 무릎에 모멘트를 주면, 부착부에 힘 센서를 넣지 않는 한 **사람이 낸 무릎 모멘트를 일반 역동역학으로 분리할 수 없습니다.** 다만 하퇴·보조기가 모두 고관절보다 원위이므로 고관절 모멘트는 구할 수 있습니다([RM] 7장 pp.161–162). 양손으로 도구를 잡는 동작처럼 사슬이 닫혀도 같은 문제가 생깁니다([RM] 5장 p.109). 의족이나 AFO에서도 "발목 모멘트"는 계산되지만, 그것은 스프링·정지 장치·마찰이 만든 것이라 근육 모멘트와 다르게 해석해야 합니다([RM] 5장 p.122).

또 한 관절의 모멘트는 연결된 **모든** 분절을 가속시킵니다(induced acceleration, [Wi] 7.4.5, [RM] 11장). 외골격이 발목에만 토크를 주어도 무릎과 고관절의 운동이 바뀔 수 있습니다. 외골격 연구에서 "생물학적 관절 모멘트가 줄었다"는 주장을 읽을 때는 접촉력을 어떻게 쟀는지부터 확인합니다(T12).

## 흔한 오해
- **"무릎 신전 모멘트 = 대퇴사두근의 힘"** → 알짜 모멘트입니다. 인대, 동시수축, 보조기가 섞입니다.
- **"봉우리가 체중의 110 %면 몸무게가 늘어난 것"** → COM의 수직 가속 때문입니다(F = m(g + a)).
- **"external flexion moment와 internal flexion moment는 같은 것"** → 부호가 반대인 같은 크기입니다. 이름 앞에 항상 internal/external을 붙입니다.
- **"파워가 0이면 근육이 쉰다"** → 등척성이면 모멘트가 커도 파워는 0입니다.
- **"관절 반력이 크면 관절면이 많이 눌린다"** → 반력과 접촉력은 다릅니다.
- **"외골격을 입어도 역동역학은 그대로 된다"** → 닫힌 사슬에서는 접촉력을 재지 않으면 사람 몫을 분리할 수 없습니다.

## 자기 점검

1. 분절 FBD에서 근위단 반력을 먼저 구해야 근위단 모멘트를 구할 수 있는 이유는?
<details><summary>정답</summary>모멘트 식에 근위단 반력이 COM에 만드는 모멘트 항이 들어가기 때문입니다. 힘 식 둘로 반력을 먼저 풀고, 그 값을 모멘트 식에 넣습니다.</details>

2. LR에서 GRF 벡터가 무릎 뒤를 지납니다. 외부 모멘트와 내부 모멘트의 이름은?
<details><summary>정답</summary>외부 굴곡 모멘트(굴곡 요구), 내부 신전 모멘트(vastii의 반응).</details>

3. 발목 모멘트가 족저굴곡근 쪽인데 발목이 배측굴곡하고 있습니다. 파워의 부호와 해석은?
<details><summary>정답</summary>음(−), 에너지 흡수. 족저굴곡근–건 단위가 늘어나며 경골 전진을 제동하는 시기(MSt–TSt, A1)입니다. 다만 늘어나는 것이 근섬유인지 힘줄인지는 파워만으로 알 수 없습니다.</details>

4. 알짜 무릎 모멘트가 작게 나왔습니다. "무릎 근육이 거의 일하지 않는다"고 말할 수 있나요?
<details><summary>정답</summary>아닙니다. 굴곡근과 신전근이 함께 수축하면 알짜 모멘트는 작아도 근육 활동과 관절 부하는 클 수 있습니다. EMG나 근골격 모델이 필요합니다.</details>

5. 100 Hz로 기록한 신발 속 수직력에서 heel transient가 잘 보이지 않는 이유는?
<details><summary>정답</summary>transient는 1–2 % GC(약 10–20 ms)로 짧아 100 Hz에서는 한두 표본뿐이고, 센서 응답·필터도 이를 깎을 수 있습니다.</details>

6. 무릎 보조기를 착용한 사람의 고관절 모멘트는 구할 수 있지만 무릎 모멘트의 "사람 몫"은 구할 수 없는 이유는?
<details><summary>정답</summary>보조기가 하퇴와 대퇴 양쪽에 붙어 닫힌 사슬을 이루면 무릎에서 사람과 보조기의 모멘트가 섞이고, 접촉력을 재지 않으면 나눌 수 없습니다. 고관절은 그 아래 모든 것(하퇴·보조기)을 한 덩어리로 보고 계산할 수 있습니다.</details>

7. 3D 무릎 내전 모멘트를 두 논문 사이에 비교하기 전에 확인할 것 세 가지는?
<details><summary>정답</summary>internal/external 중 무엇인지, 어느 좌표계(근위·원위 분절, JCS, 진행면)로 분해했는지, 정규화 단위(N·m/kg, N·m/(BW·LL) 등).</details>
