## 본문

### 1. 신호와 잡음: 보행은 낮은 주파수에 산다

측정한 파형은 신호 + 잡음이다. 반복 운동의 성분은 stride 주파수의 정수배(harmonic)에 모인다. 분당 120걸음이면 stride 주파수는 1 Hz이고 harmonic은 2, 3, 4 Hz …다([Wi] 3.5.1 p.53). Winter가 20명의 발끝 마커 수직 변위를 분석했을 때 전력의 99.7%가 아래 7개 harmonic, 곧 약 6 Hz 아래에 있었다([Wi] 2.2 p.27). 걷기 운동학에 "6 Hz" cutoff가 관례가 된 근거다. 이 숫자는 **걷기 마커 변위**의 경험값일 뿐이다. 달리기, 충격을 담은 가속도계, EMG, 지면반력의 충격 성분에는 맞지 않는다.

잡음은 운동 자체에서 오지 않은 성분(전자 잡음, 카메라 분해능, 마커 재구성 오차)이다. 무작위 잡음은 높은 주파수까지 평평하게 퍼진다. 평활화의 대전제는 "신호와 잡음이 서로 다른 주파수에 있다"는 것이다([RM] 12장 p.285). 이 전제가 깨지는 경우를 기억해 둔다. 순간 충격은 신호인데 고주파이고, 피부 움직임 오차는 잡음인데 보행 주파수에 있다(T08).

### 2. 표본화와 aliasing

**표본화 정리:** 신호에 들어 있는 가장 높은 주파수의 2배보다 빠르게 표본을 뜨면 연속 신호가 표본으로 완전히 결정된다([Wi] p.23; [RM] 12장 pp.282–284). 이보다 느리면 높은 주파수 성분이 사라지기만 하는 것이 아니라 **낮은 가짜 주파수로 접혀 들어온다**(aliasing). 같은 표본 시각에서 두 신호의 값이 똑같아져 구별할 수 없게 되는 것이 본질이다. 9 Hz 사인을 10 Hz로 뜨면 1 Hz 사인과 같은 표본이 나온다. 접혀 들어온 성분은 진짜 저주파 성분과 구별이 안 되므로 **기록한 뒤에는 디지털 필터로 되돌릴 수 없다.** 표본화 전에 아날로그 antialiasing 필터가 있어야 한다([RM] p.285). 진동·충격이 큰 착용 센서를 낮은 표본화율로 쓸 때 특히 조심한다.

실무 규칙 몇 가지:

- 이론상 2배면 스펙트럼은 맞지만, 시간 영역에서 봉우리의 크기와 시각을 놓치지 않으려면 관심 최고 주파수의 **5–10배**로 뜬다([RM] p.282).
- 기록 **길이**는 가장 낮은 주파수가 정한다. 보행이면 stride 주파수가 기본 주파수이고, 조용한 서기처럼 기본 주파수가 없는 과제는 COP 성분이 0.2 Hz 아래에 몰려 1분 이상이 필요하다([Wi] p.25).
- 힘·EMG 같은 아날로그 채널은 영상 프레임률의 정수배로 뜨면 동기화가 쉽다([RM] p.285).
- 용어 주의: 대부분의 문헌과 scipy에서 Nyquist 주파수는 **fs/2**다. 그런데 [RM] 12장은 "Nyquist sampling frequency"를 필요한 최소 표본화율(최고 주파수의 2배)로 쓴다. 같은 낱말이 다른 양을 가리키므로, 이 과정에서는 "표본화율 fs, 그 절반 fs/2(Nyquist 주파수)"로 통일한다.

BMC의 `signal_basic_properties` 노트북이 aliasing을 그림으로 다룬다.

### 3. Fourier 분석: 무엇을 알려 주고 무엇을 숨기는가

Fourier 급수의 계수는 "신호에 그 주파수의 사인(코사인)파를 곱해 평균을 내고 2배 한 것"이다([RM] p.281; [Wi] pp.20–21). 사인 계수와 코사인 계수의 제곱합이 그 주파수의 세기다. FFT는 이것을 빠르게 계산하는 알고리즘이고, N개 표본에서 0부터 fs/2까지 N/2개 bin을 주며 **bin 폭은 fs/N**이다.

여기서 두 가지를 구분한다. bin 폭과 **진짜 해상도**다. 0을 덧붙이면(zero padding) bin이 촘촘해지지만 이것은 곡선 위에 점을 보간해 넣는 것과 같고, 가까운 두 주파수를 새로 갈라 주지는 않는다. 진짜 해상도는 기록 길이 T로 정해진다(약 1/T Hz)([RM] p.281). 그리고 패딩·창 함수는 전체 파워를 줄이므로 절대 파워를 비교하려면 보정하거나 기록마다 같은 설정을 쓴다. freeze index처럼 두 대역의 **비율**을 쓰면 상수 보정은 상쇄되지만, 대역 파워 자체를 feature로 쓸 때는 그렇지 않다.

Fourier 분석의 숨은 가정은 **stationarity**다. 계수는 분석 구간 전체의 평균이라서, 어떤 성분이 구간 일부에만 있어도 "전체에 걸친 평균 진폭"으로 나온다. swing에서는 빠르고 stance에서는 거의 멈추는 발 마커는 harmonic 9개로 다시 합쳐도 원래 모양과 눈에 띄게 다르다([Wi] 2.2.4.5 pp.28–29). FOG 떨림처럼 몇 초만 나타나는 성분을 보려면 짧은 window를 밀며 FFT를 하는(STFT) 시간–주파수 분석이 필요하다([RM] p.282). 예를 들어 Bächlin 2010의 설정은 64 Hz × 4 s = 256 표본, 256-point FFT로 bin 폭이 0.25 Hz다. 3 Hz처럼 두 대역의 경계에 걸린 bin을 어느 쪽에 넣는지는 논문에 없으므로 분석자가 규칙을 정해 적어야 한다. window 길이는 trade-off다. 길수록 스펙트럼은 안정되지만 반응이 늦다(Bächlin V-C절에서는 4.5 s 근처가 최적이었다).

### 4. 상관함수: 닮음과 지연

자기상관(autocorrelation)은 신호를 τ만큼 밀면서 자기 자신과의 상관을 계산한 함수다. τ = 0에서 1로 최대이고, 짝함수이며, 주기 신호는 같은 주기로 반복하는 자기상관을 갖고 위상 정보는 사라진다. 백색 잡음은 τ = 0에서만 1이다. 그래서 잡음에 묻힌 주기 성분이 τ ≠ 0 구간에서 드러난다([Wi] 2.1 pp.11–13). 반드시 평균을 먼저 뺀다. 남아 있으면 모든 τ에 상수가 더해져 상관이 부풀려진다(p.15).

보행에서의 쓰임은 단순하다. 한쪽 발 힘 신호의 자기상관에서 τ = 0을 뺀 첫 큰 봉우리의 지연이 **stride time**, 양발 합 신호에서는 **step time**이다. 상호상관(cross-correlation)은 짝함수가 아니고, 최대가 τ = 0이 아닌 곳에 있을 수 있어 두 신호 사이의 **지연**, 곧 어느 쪽이 앞서는지를 알려 준다. 척추기립근 EMG에서 C7이 L4보다 약 70 ms 앞선 예가 있다([Wi] pp.17–18). 라이브러리마다 지연의 부호 정의가 다르므로 가상 신호로 먼저 확인한다.

### 5. 필터: 진폭, 위상, 그리고 두 번 거르기

필터의 주파수 응답은 주파수별 출력/입력 진폭비다. low-pass의 cutoff는 진폭비가 0.707(전력 절반, −3 dB)이 되는 주파수다([Wi] pp.25–26; [RM] p.287). Butterworth는 통과대역이 가장 평평하고 roll-off가 빠르지만 계단 입력에 약간의 overshoot가 있다. 계수의 √2를 2로 바꾼 critically damped 필터는 overshoot가 없고 느리다. 두 번 미분할 마커 궤적에는 Butterworth, onset을 찾을 정류 EMG에는 critically damped가 낫다는 것이 [RM]의 권고다(p.289).

**위상 지연.** recursive(IIR) 필터는 진폭만 줄이는 것이 아니라 출력을 늦춘다. 2차 low-pass는 cutoff에서 90° 늦고, 통과대역 안의 harmonic들도 서로 다른 만큼 늦어져 파형이 틀어진다([Wi] 3.5.4.2 pp.56–57). 한 번 거른 자료를 **시간을 거꾸로** 한 번 더 거르면 지연이 같은 크기의 앞섬으로 상쇄되어 zero-phase가 된다. scipy의 `filtfilt`가 하는 일이다. 대가가 둘 있다.

첫째, **진폭 응답이 제곱된다.** cutoff에서 0.707이었던 이득이 0.5(−6 dB)가 되어 실제 −3 dB 지점이 낮아진다. 원하는 cutoff를 지키려면 한 번 통과용 필터를 미리 높여 설계한다. 2차 Butterworth를 n번 통과시킬 때의 보정계수는 한 번 통과의 |H|² = 1/(1 + (Ω/Ωc)⁴)에서 |H|^n = 2^(−1/2)이 되는 점을 풀어 얻는다.

```
C = (2^(1/n) − 1)^(1/4)       n = 2(앞뒤 한 번씩)이면 C ≈ 0.802
설계 cutoff ≈ 원하는 cutoff / C   (tan 보정을 넣으면 조금 다르다)
```

([Wi] p.56; [RM] 식 12.18.) 그래서 보정 없이 `filtfilt(butter(2, 6 Hz))`를 쓰면 실제 −3 dB 지점은 약 4.8 Hz다. 논문 Methods를 읽을 때 "보정했는가"를 확인할 이유다. 둘째, **미래 표본이 필요하다.** zero-phase 필터는 오프라인 전용이고, 실시간 제어에서는 causal 필터의 지연을 지연 예산 안에 넣어야 한다(T12).

아래 코드는 이 두 사실 가운데 첫째를 확인하고, 다음 절의 미분 잡음 증폭을 숫자로 보인다.

```python
import numpy as np
from scipy import signal

fs, fc = 100.0, 6.0                       # 표본화 100 Hz, 원하는 cutoff 6 Hz
f = np.linspace(0.01, 20, 20000)

def gain_after_filtfilt(fc_design):
    b, a = signal.butter(2, fc_design / (fs / 2))
    _, h = signal.freqz(b, a, worN=f, fs=fs)
    return np.abs(h) ** 2                 # 앞뒤 두 번 지나가면 진폭 응답이 제곱된다

def minus3db(g):
    return f[np.argmin(np.abs(g - 1 / np.sqrt(2)))]

C = (2 ** 0.5 - 1) ** 0.25                # 2차 Butterworth, 두 번 통과 보정계수
fc_exact = fs / np.pi * np.arctan(np.tan(np.pi * fc / fs) / C)   # tan 보정까지 넣은 설계값
print(f"보정계수 C = {C:.3f}")
print(f"보정 없이 butter(2, 6 Hz)+filtfilt: 실제 -3 dB 지점 {minus3db(gain_after_filtfilt(fc)):.2f} Hz")
print(f"설계 cutoff를 {fc_exact:.2f} Hz로 올리면:       실제 -3 dB 지점 {minus3db(gain_after_filtfilt(fc_exact)):.2f} Hz")

# 미분이 잡음을 키우는 정도: 1 Hz 신호(진폭 50 mm) + 20 Hz 잡음(진폭 0.5 mm, 1%)
# n번째 harmonic의 진폭은 한 번 미분할 때마다 (2*pi*f)배 → 비율은 f의 k제곱으로 커진다
for k, name in [(1, "속도"), (2, "가속도")]:
    print(f"{name}: 잡음/신호 진폭비 = {(0.5 * 20**k) / (50 * 1**k):.0%}")
```

실행 출력(neurobio 환경):

```
보정계수 C = 0.802
보정 없이 butter(2, 6 Hz)+filtfilt: 실제 -3 dB 지점 4.83 Hz
설계 cutoff를 7.43 Hz로 올리면:       실제 -3 dB 지점 6.00 Hz
속도: 잡음/신호 진폭비 = 20%
가속도: 잡음/신호 진폭비 = 400%
```

**책의 식을 옮기지 말아야 할 곳.** [RM] 12장 p.289의 Butterworth 계수식에는 인쇄 오류가 두 곳 있다(C4 분자는 2(1 − Ω_N²), C5 분자는 √2·Ω_N − Ω_N² − 1이 맞다). 같은 장 p.287에는 low-pass가 cutoff 아래를 감쇠한다고 거꾸로 적힌 문장이 있다(바로 아래 목록이 맞다). 계수를 손으로 구현하지 말고 scipy를 쓰고, 직접 구현했다면 통과대역 이득(계수 합)이 1인지 확인한다. [Wi]의 2차 필터 식(pp.27–28)은 scipy와 소수 다섯째 자리까지 같지만 되먹임 계수의 부호를 반대로 쓴다.

그 밖의 실무: 필터는 기록의 처음과 끝을 왜곡하므로 분석 구간 앞뒤로 여유를 기록하거나 반사 padding을 쓴다([RM] p.288). 이동평균은 쉽지만 주파수 선택성이 없어 신호와 잡음을 가르지 못한다. 전원 잡음용 notch는 EMG에 권하지 않는다(EMG 자체가 그 대역에 파워가 많다). EMG envelope의 cutoff는 근육 수축의 시간 특성에서 오는 다른 논리다(T04).

### 6. 미분은 왜 잡음을 키우는가

위치를 x = Σ X_n·sin(nω0·t + θ_n)으로 쓰면, 속도의 n번째 harmonic 진폭은 nω0·X_n, 가속도는 (nω0)²·X_n이다. 높은 harmonic일수록 미분할 때마다 n배씩 커진다([Wi] 3.5.3 p.54). 위의 코드처럼 1% 잡음이 속도에서 20%, 가속도에서 400%가 된다. 그래서 운동학 자료는 **미분하기 전에** 거른다. 수평 막대를 여러 장비로 동시에 잰 검증 실험에서, 거른 뒤 차분한 각가속도는 가속도계와 잘 맞았고 필터 없이 차분한 값은 잡음에 묻혀 쓸 수 없었다([Wi] 3.5.5 pp.60–61; Pezzack 1977의 비교는 [RM] 1장 pp.28–29). 프레임률을 올리면 오히려 차분 잡음이 커진다.

차분 식도 정확히 쓴다. 인접 두 표본의 차분은 두 시점 **사이**의 속도다. 같은 시점에 맞추려면 중심차분 v_i = (x_{i+1} − x_{i−1})/(2Δt)을, 가속도는 a_i = (x_{i+1} − 2x_i + x_{i−1})/Δt²를 쓴다([Wi] p.64). `np.gradient`는 양 끝점에서 한쪽 차분을 쓰므로 끝 몇 점의 가속도는 믿지 않는다. 각도는 rad으로 바꿔 미분하고, 360° 경계를 넘으면 unwrap한다.

### 7. cutoff를 어떻게 고르는가: residual analysis

스펙트럼을 보고 "전력의 몇 %까지"로 고르는 방법은 필터가 이상적으로 가파르다고 가정한다. Winter의 residual analysis는 실제 필터 특성을 판단에 넣는다([Wi] 3.5.4.3 pp.57–59).

1. cutoff 후보(예: 1–20 Hz)마다 zero-phase 필터를 걸고, 원자료와의 **RMS 잔차** R(fc) = √(mean((x − x̂)²))를 계산한다.
2. R을 fc에 대해 그린다. 순수 잡음만 남은 높은 주파수 쪽에서는 거의 직선으로 줄고, 낮은 fc에서는 신호가 깎이면서 곡선이 그 직선 위로 솟는다.
3. 높은 주파수 쪽 직선 부분에 회귀선을 맞춰 0 Hz까지 늘린다. 절편이 잡음의 RMS 추정값이다.
4. 그 높이의 수평선이 잔차 곡선과 만나는 주파수를 cutoff로 고른다. 이 점에서 "깎인 신호 ≈ 통과한 잡음"이다.

[RM] 12장 p.288은 같은 생각을 "잔차의 **합**" 기준으로 소개하는데, zero-phase low-pass는 평균을 보존하므로 잔차의 합은 cutoff가 아주 낮아질 때까지 거의 0이라 기준으로 불안정하다. RMS 방식을 쓴다.

결과는 하나의 숫자가 아니다. Winter의 예에서 빨리 움직이는 뒤꿈치·발허리 마커는 약 6 Hz까지, 갈비뼈·고관절 마커의 수직 변위는 약 3 Hz까지 신호가 있었다([Wi] p.59). BMC `residual_analysis`의 문제 하나는 바로 Winter 표 A.1의 마커 좌표에 이 방법을 적용하는데, **좌표마다 cutoff가 약 2.9–7.3 Hz로 갈린다.** 그래서 실제 결정은 "마커·방향마다 다르게 쓸 것인가, 공통 cutoff 하나를 어떤 근거로 고를 것인가"다. 그 밖의 단서: 이 기준은 변위에 대한 것이라 속도·가속도에 최적인 cutoff는 더 높게 나온다는 연구가 있고, 최적값이 표본화 주파수에도 의존한다([Wi] 3.5.4.4 pp.59–60). 직선 구간을 어디로 잡느냐에 따라 값이 달라지므로 그 구간을 보고한다. 대안으로 측정계 오차를 넣어 평활 정도를 고르는 스플라인(GCV) 방식이 있고, 결과는 zero-lag Butterworth와 비슷하다([RM] pp.289–290).

### 8. 시간 정규화와 ensemble 평균이 숨기는 것

stride마다 길이가 다른 신호를 비교하려면 각 stride를 같은 점 수(보통 101점 = 0–100% GC)로 다시 뜬다. k번째 새 점은 원자료의 "소수 위치"이므로 양옆 표본을 선형보간한다([Wi] 2.3 pp.31–32; [RM] 1장 pp.23–25). 이렇게 겹친 주기들의 평균 ± SD가 ensemble 그림이고, 환자 곡선을 정상군 띠 위에 겹치는 것이 임상 보고의 기본 형식이다.

숨기는 것도 셋 있다. (1) **초 단위 시간이 사라진다.** loading rate(N/s), 충격량처럼 시간이 들어가는 변수는 정규화 전 자료로 계산한다([Wi] p.32). (2) **봉우리가 뭉개진다.** 주기마다 봉우리 시점이 다르면 평균 곡선의 봉우리는 낮고 넓어진다. 평균 곡선의 최댓값은 각 주기 최댓값의 평균이 아니다. (3) **변동성 지표가 다르다.** [Wi]의 파형 CV(각 시점 SD의 제곱평균을 평균 파형 절대값의 평균으로 나눈 것)는 파형 모양의 재현성이고, stride time CV(시공간 변수 하나의 SD/평균)와 다른 양이다. 0 근처를 오가는 모멘트처럼 분모가 작은 신호에서는 파형 CV가 커 보인다.

선형 정규화는 heel strike 두 개만 맞춘다. 주기 안 특징점(예: 최대 굴곡 시점)까지 맞추는 것이 landmark registration이다. 크기 차이를 깨끗이 보려면 쓸모가 있지만, 타이밍 차이가 연구 질문이라면 바로 그 정보를 지운다. 병적 파형처럼 특징점이 없는 곡선이 섞이면 오히려 왜곡을 만든다([RM] 14장 pp.330–331).

### 9. 파형 전체를 다루기: PCA와 SPM

곡선을 봉우리 몇 개로 줄이는 방식에는 세 가지 문제가 있다. 시간 정보 대부분을 버리고, 연구마다 정의가 다르며, 병적 파형에서는 그 봉우리 자체가 없을 수 있다. 무릎 OA 연구에서 무릎 내전 모멘트의 둘째 봉우리가 환자의 절반 이상, 무증상군의 약 3할에서 뚜렷하지 않았다는 보고가 있다([RM] 14장 pp.318–319).

**파형 PCA**는 행 = 사람(n), 열 = 시점(p, 예: 101)인 행렬을 만들고 평균 파형을 뺀 뒤 공분산 행렬을 고유분해한다. 고유벡터가 loading vector(파형과 같은 길이의 "변동 모드"), 각 사람과의 내적이 PC score, 고유값/고유값의 합이 설명 분산이다(pp.319–324). 주성분의 최대 개수는 평균을 뺀 뒤라 min(n − 1, p)다. 해석은 평균 ± 1 SD(score) × loading으로 두 곡선을 다시 그려 그 PC 하나의 효과를 보는 것이 표준이다. 무릎 굴곡각 예에서는 첫 PC가 곡선 전체의 평행 이동(크기), 둘째가 봉우리–골짜기 진폭(가동 범위), 셋째가 위상 이동을 잡았다(pp.324–325). 지킬 것: 고유벡터의 부호는 임의라서 "+score = 크다"로 읽지 않는다. 설명 분산이 큰 PC가 군을 가르는 PC라는 보장은 없다. 두 군을 **합친 행렬에서 한 번** PCA를 한다. PC score를 분류 feature로 쓸 때는 PCA를 train fold 안에서만 맞춘다(누수 방지, [RM] 14장에는 없는 주의). 한 사람의 여러 stride를 행으로 넣으면 n이 부풀려진다.

**SPM(statistical parametric mapping)**은 뇌영상에서 온 방법으로, 파형의 **모든 시점**에서 검정 통계량을 계산하고 연속된 곡선의 성질을 반영한 다중비교 보정으로 "주기의 어느 구간에서 차이가 있는가"를 보여 준다. [W]는 미리 정한 이산 변수만 보는 방식의 regional focus bias(어디를 볼지 미리 정하는 데서 오는 편향)를 지적하며 SPM을 소개한다([W] 5장 pp.92–94). Python 구현으로 spm1d가 있다(Pataky 2012). SPM도 "어디가 다른가"를 말할 뿐 "왜 다른가"는 말하지 않는다.

## 흔한 오해

- **"6 Hz는 보행 신호의 표준 cutoff다."** 걷기 마커 변위의 경험값이다. 가속도계·지면반력·EMG에는 맞지 않고, 마커와 방향마다 달라도 된다.
- **"aliasing은 나중에 low-pass로 지우면 된다."** 접혀 들어온 성분은 진짜 저주파와 구별이 안 된다. 표본화 전에 막아야 한다.
- **"zero padding으로 해상도를 높였다."** bin만 촘촘해진다. 해상도는 기록 길이가 정한다.
- **"filtfilt는 위상만 없애고 나머지는 같다."** 진폭 응답이 제곱되어 실효 cutoff가 약 0.8배로 내려가고, 미래 표본이 필요해 실시간에는 못 쓴다.
- **"프레임률을 올리면 가속도가 좋아진다."** 차분 잡음은 오히려 커진다. 필터가 먼저다.
- **"평균 곡선의 봉우리 = 대표 봉우리 값."** 봉우리 시점이 흩어져 있으면 평균 곡선의 봉우리는 낮아진다.
- **"PC1이 분산을 가장 많이 설명하니 군 차이도 PC1에 있다."** 군 차이는 작은 PC에 있을 수 있다. 남긴 PC를 각각 해석·검정한다.

## 자기 점검

1. 100 Hz로 기록한 가속도에 원래 70 Hz 진동 성분이 있었다(antialiasing 필터 없음). 스펙트럼의 어디에 나타나는가?
<details><summary>정답</summary>fs/2 = 50 Hz를 넘으므로 |70 − 100| = 30 Hz에 가짜 성분으로 나타난다. 기록 뒤에는 진짜 30 Hz 성분과 구별할 수 없다.</details>

2. 64 Hz, 4 s window의 FFT bin 폭은? 같은 신호를 2 s window로 자르면 무엇을 얻고 무엇을 잃는가?
<details><summary>정답</summary>64/256 = 0.25 Hz. 2 s면 bin 폭 0.5 Hz로 주파수 해상도와 스펙트럼 안정성을 잃는 대신, 짧은 사건에 더 빨리 반응한다(지연 감소).</details>

3. 논문에 "4th-order zero-lag Butterworth, 6 Hz"라고만 적혀 있다. 실제 −3 dB 지점으로 가능한 두 값을 말하고, 무엇을 확인해야 하는지 말하라.
<details><summary>정답</summary>2차 필터를 보정 후 두 번 걸었다면 6 Hz, 보정 없이 두 번 걸었다면 약 4.8 Hz(6 × 0.8). 통과 횟수 보정 여부를 확인하고, 자기 연구에서는 명시한다.</details>

4. 위치 잡음 진폭이 기본파의 0.5%이고 잡음이 15번째 harmonic에 있다면, 가속도에서 잡음은 기본파의 몇 %인가?
<details><summary>정답</summary>0.5% × 15² = 112.5%. 잡음이 신호보다 커진다.</details>

5. residual analysis를 Winter 표 A.1의 마커 16개 좌표에 하니 cutoff가 2.9–7.3 Hz로 나왔다. 하나의 공통 cutoff를 쓰겠다면 어떤 근거를 적어야 하는가?
<details><summary>정답</summary>목적 변수(예: 발목각 가속도에 쓰이는 좌표)의 cutoff를 기준으로 했는지, 가장 높은 값을 택해 신호 손실을 피했는지 등 선택 규칙과 잔차 직선 구간을 명시한다. 마커별 cutoff를 쓰는 대안과 결과 민감도도 함께 보고하면 좋다.</details>

6. 시간 정규화한 VGRF로 loading rate(N/s)를 계산하면 왜 틀리는가?
<details><summary>정답</summary>0–100%로 바꾸면 초 단위 시간이 사라져, stride 길이가 다른 사람·주기의 기울기가 같은 척도가 아니다. 정규화 전 자료에서 계산한다.</details>

7. PD군과 대조군의 참가자 평균 파형을 따로 PCA한 뒤 PC1 score를 t-test로 비교했다. 문제는?
<details><summary>정답</summary>군마다 loading vector가 달라 score가 같은 축 위의 값이 아니다. 두 군을 합친 행렬에서 PCA를 한 번 하고, 부호 임의성과 다중비교를 고려해 각 PC를 비교한다.</details>
