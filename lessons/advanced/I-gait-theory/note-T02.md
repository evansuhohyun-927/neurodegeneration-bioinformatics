## 본문

### 1. 좌표계: 먼저 축 이름을 확인한다
**GCS(전역 좌표계)** 는 실험실에 고정된 관성 기준틀이고, **LCS(국소 좌표계)** 는 분절에 붙어 함께 움직입니다. LCS의 축이 GCS에 대해 어떻게 놓였는지가 곧 분절의 방향입니다([RM] 1장 pp.9–10). 강체 분절 하나는 3D에서 자유도 6(위치 3 + 방향 3), 2D에서 3(x, y, θ)입니다([RM] 1장 pp.11–12).

축 이름은 통일되어 있지 않습니다. 같은 책 안에서도 다릅니다.
- [Wi] 2D(3.6절, 4–6장, 부록 A): X = 진행 방향, **Y = 수직**. 반시계 회전 +.
- [Wi] 3D(3.1.1, 7.1절): X = 진행 방향, **Z = 수직**, Y = 좌우. force plate 식(p.99)은 수직력을 F_Y로 씁니다.
- [RM] 1장(ISB 2D 규약): X = 진행, Y = 위, Z = 오른쪽.
- [RM] 2장(3D): **Y = 전방**, Z = 위, X = 오른쪽.

회전 부호는 오른손 법칙으로 정합니다. 오른손 손가락을 회전 방향으로 감았을 때 엄지가 +축을 향하면 +입니다. 피험자가 오른쪽을 보고 걷는 시상면을 오른쪽에서 보면 반시계 방향이 +입니다([RM] 1장 p.24). 자료(gaitpdb, WinterTableA1, IMU 파일)를 받을 때마다 축 정의를 데이터 사전에 한 줄로 적어 두는 습관이 이 혼란을 막습니다.

### 2. 분절각: atan2와 불연속
분절각은 분절 하나가 전역 기준(보통 오른쪽 수평선)과 이루는 각입니다. 두 마커 좌표로 계산합니다.

```
θ = atan2(Δy, Δx)        # 결과는 rad, 범위 (−π, π]
```

`atan(Δy/Δx)`는 x가 음수인 사분면에서 180° 틀리고, 분절이 거의 수직이면 0으로 나누게 됩니다. 반드시 `atan2`를 씁니다([RM] 1장 p.27).

어느 마커에서 어느 마커로 향하는 벡터를 쓰는지가 교재마다 다릅니다. [Wi] 3.6.1은 **원위 마커 → 근위 마커**, [RM] 1장은 **근위 끝에서 원위 쪽으로**의 방향을 씁니다. 두 정의의 분절각은 180° 차이가 나지만, 관절각을 두 분절각의 차로 구하면 그 차이가 상쇄됩니다. 분절각 자체를 보고하거나 다른 연구와 비교할 때만 문제가 됩니다.

±180° 경계를 넘으면 한 프레임 사이에 각이 340°처럼 튑니다. 프레임 사이에 180° 넘게 변하지 않는다고 가정하고 **360°** 를 더하거나 빼서 이어 붙입니다(`numpy.unwrap`). [RM] 1장 p.26의 인쇄본은 "180°"를 더하거나 뺀다고 적었지만, 책의 예를 맞추려면 360°가 맞습니다. 미분하기 전에 반드시 unwrap합니다.

### 3. 관절각: 정의와 부호는 반드시 명시한다
관절각은 인접한 두 분절각의 차입니다. [Wi]의 2D 정의(p.63)는:
- 무릎 = θ_thigh − θ_leg, 양수 = 굴곡
- 발목 = θ_leg − θ_foot + 90°, 양수 = **plantarflexion**

그런데 같은 책 부록의 Table A.4 발목 값은 **dorsiflexion이 양수**입니다(toe-off 무렵 약 −20°). 본문 식에 −1을 곱한 것과 같습니다. 그리고 부록 표를 재현하려면 다리 분절은 발목 → **fibula head**, 발 분절은 **5th metatarsal → heel**로 정의해야 합니다(toe 마커가 아님). 운동역학용 다리 분절(발목 → 무릎)과는 약 4° 다릅니다. 실습 I3이 부록 규약(dorsiflexion +)을 쓰는 이유는 Perry 등 임상 관례와 같기 때문입니다.

**생체역학식 vs 임상식.** 생체역학식은 두 분절각의 차를 오른손 법칙 부호 그대로 씁니다. 완전히 편 무릎이 180° 근처가 됩니다. 임상식은 해부학적 자세를 0°로 두고 "굴곡 몇 도"처럼 운동 이름으로 방향을 나타냅니다([RM] 1장 pp.26–27). 또 같은 전역 부호 규칙에서 무릎 굴곡이 + 회전이면 고관절 굴곡은 − 회전입니다. 임상식으로 바꿀 때 관절마다 부호를 따로 뒤집어야 하는 이유입니다.

발목의 "0°"도 약속입니다. 실제로 경골과 발은 약 90°를 이루지만 그것을 0°로 둡니다([W] 2장 p.21).

**고관절은 두 가지 각이 있다.** Perry는 고관절을 **thigh 각**(수직선 기준 대퇴의 각)으로 서술합니다. 골반 기준의 **hip 각**은 대퇴 움직임과 골반 기울기가 합쳐진 값입니다. 같은 걸음에서 thigh 각은 IC 굴곡 20° → TSt 끝 신전 20°이고, hip 각은 굴곡 30° → 신전 10°입니다. 차이 약 10°가 정상 보행의 평균 골반 전방경사입니다([P] 6장 Hip). TSt 끝의 thigh 신전 20°는 고관절만으로는 불가능하고, 고관절 완전 신전 + 골반 전방경사 증가 + 골반 후방 회전이 합쳐진 "겉보기 과신전"입니다. [W] 2장 p.21도 두 정의가 있다고 짚습니다. 몸통을 숙이면 hip 각에는 굴곡으로 나오지만 thigh 각에는 나오지 않습니다. 마커로 계산한 각을 Perry 값과 비교하려면 어느 정의인지부터 맞춥니다.

### 4. 각속도·각가속도와 단위
중앙차분으로 구합니다([Wi] 3.6.2, [RM] 1장 p.28).

```
ω_i = (θ_{i+1} − θ_{i−1}) / (2Δt)          # rad/s
α_i = (θ_{i+1} − 2θ_i + θ_{i−1}) / Δt²      # rad/s²
```

각도는 그래프에서 deg로 그려도 계산에는 rad를 씁니다. v = rω, a = rα 같은 식은 rad에서만 성립합니다(°/s로 계산하면 약 57배 틀림). 이 식들은 **필터를 거친 자료에만** 씁니다. 미분이 고주파 잡음을 n배, n²배로 키우기 때문입니다(T09). 중앙차분은 앞뒤 표본이 필요하므로 처음·마지막 점은 믿지 않고, 관심 구간 앞뒤로 여분의 프레임을 수집합니다.

### 5. 2D의 한계와 3D로 가는 이유
시상면 2D 분석은 보행의 큰 움직임이 시상면에 몰려 있어 단순하고 유용합니다([RM] 1장 p.12). 그러나 다리가 평면 밖으로 돌면 투영된 각은 실제 굴곡각과 달라집니다. 그리고 **세 평면에 투영한 2D 각 세 개를 모아도 3D 관절각이 되지 않습니다**([RM] 2장 pp.50, 59).

3D에서 분절의 방향을 정하려면 분절마다 **일직선이 아닌 마커 3개 이상**이 필요합니다(마커 하나가 3, 둘째가 2, 셋째가 1 자유도를 더함, [RM] 2장 p.45; [Wi] 3.3.4). 표준 절차는 서 있는 보정 시행에서 뼈 지표 마커로 해부학 좌표계를 **정의**하고, 걷는 동안에는 분절에 붙인 추적 마커(cluster)로 그것을 **추적**하는 것입니다([Wi] 7.2, [RM] 2장 p.39). 이때 피부·근육이 뼈와 따로 움직이며 생기는 **연부조직 artifact**가 가장 큰 오차원 중 하나입니다. 마커에서 분절 자세를 얻는 방법(직접법, 분절 최적화, 전역 최적화=IK)과 그 오차는 T08에서 다룹니다.

### 6. Cardan 각: 회전행렬을 세 수로 바꾼 것
3D 관절각은 근위 분절 좌표계에 대한 원위 분절 좌표계의 상대 방향입니다. 그 본체는 3×3 회전행렬이고, 세 각은 그 행렬을 사람이 읽기 쉽게 매개변수화한 것입니다([RM] 2장 p.50).

[Wi] 7.1.2와 [RM] 2장 p.52는 같은 형태의 x–y–z Cardan 순서를 씁니다. 각 회전(c = cos, s = sin)을 좌표 변환 행렬로 쓰면

```
Rx(α) = [[1, 0, 0], [0,  c,  s], [0, −s,  c]]
Ry(β) = [[c, 0, −s], [0,  1,  0], [s,  0,  c]]
Rz(γ) = [[c,  s, 0], [−s, c,  0], [0,  0,  1]]
R = Rz(γ) · Ry(β) · Rx(α)
```

행렬에서 각을 되찾는 식은 α = atan2(−R₃₂, R₃₃), β = asin(R₃₁), γ = atan2(−R₂₁, R₁₁)입니다. 하지에서 이 순서의 해부학적 의미는 첫째 = 굴곡–신전(근위 분절의 외측축), 둘째 = 외전–내전(floating 축), 셋째 = 축 회전(원위 분절의 장축)입니다. Grood & Suntay의 **JCS**는 근위 분절의 축 하나, 원위 분절의 축 하나, 그 둘에 수직인 floating 축으로 관절 회전을 정의하며, 이 Cardan 순서와 같은 값을 줍니다([RM] 2장 pp.53–55). ISB는 하지에 X–Y–Z 순서를 권합니다([Wi] p.158).

세 가지 주의점이 있습니다.
- **순서가 결과를 바꾼다.** 회전 순서는 12가지이고 행렬 곱은 교환되지 않습니다. 순서와 축 정의를 보고하지 않은 3D 각은 비교할 수 없습니다.
- **gimbal lock.** 둘째 각이 ±90°가 되면 첫째와 셋째 회전축이 겹쳐 두 각을 따로 구할 수 없습니다. [RM] 2장은 둘째 각이 약 40°를 넘으면 해부학적 해석이 깨진다고 경고합니다. 하지 보행에서는 대개 문제없지만 어깨에서는 흔합니다.
- **작은 각은 잡음이 크다.** 보행 중 고관절·무릎의 외전–내전과 축 회전은 범위가 작아 연부조직 artifact와 마커 오차의 비중이 큽니다. 임상 검사실에 따라서는 무릎의 이 두 각을 신뢰하지 않기도 합니다([RM] 2장 p.53).

좌우 다리도 신경 써야 합니다. 축 규약상 왼쪽 분절의 x축이 내측을 향하면, 좌우가 같은 해부학적 부호를 갖도록 왼쪽의 외전–내전·축 회전 각에 −1을 곱합니다([RM] 2장 p.54).

### 7. 각도의 미분은 각속도가 아니다
Cardan 각의 시간미분(α̇, β̇, γ̇)은 분절 각속도 벡터의 성분이 아닙니다. 원위 분절 축에서 본 각속도는 [Wi] 7.3(식 7.7b)의 변환으로 얻습니다.

```
ω_x = cos β · cos γ · α̇ + sin γ · β̇
ω_y = −cos β · sin γ · α̇ + cos γ · β̇
ω_z = sin β · α̇ + γ̇
```

둘째 각 β가 0이면 ω_z = γ̇이 되지만, β가 커질수록 첫째 각의 변화가 다른 성분으로 섞여 들어갑니다. 자이로스코프가 재는 것은 이 ω(센서 축 성분)이지 Euler·Cardan 각의 변화율이 아닙니다. IMU 각속도를 적분해 방향을 구할 때(I9, I11) 각을 단순히 적분하면 안 되는 이유입니다([RM] 2장 p.58).

아래 코드는 이 노트를 위해 새로 작성했습니다. 가상의 무릎 자세로 ① 각 되찾기, ② 순서 의존성, ③ 각도 변화율 vs 각속도, ④ gimbal lock을 확인합니다.

```python
import numpy as np

def Rx(a): c, s = np.cos(a), np.sin(a); return np.array([[1, 0, 0], [0, c, s], [0, -s, c]])
def Ry(b): c, s = np.cos(b), np.sin(b); return np.array([[c, 0, -s], [0, 1, 0], [s, 0, c]])
def Rz(g): c, s = np.cos(g), np.sin(g); return np.array([[c, s, 0], [-s, c, 0], [0, 0, 1]])

def cardan_xyz(a, b, g):          # 근위 → 원위 변환, x(굴곡) → y(외전) → z(축회전) 순서
    return Rz(g) @ Ry(b) @ Rx(a)

def angles_xyz(R):                # 행렬에서 세 각을 되찾기
    a = np.arctan2(-R[2, 1], R[2, 2])
    b = np.arcsin(R[2, 0])
    g = np.arctan2(-R[1, 0], R[0, 0])
    return np.degrees([a, b, g])

ang = np.radians([40.0, 10.0, -8.0])   # 굴곡 40°, 외전 10°, 축회전 -8° (가상의 무릎 자세)
R = cardan_xyz(*ang)
print("되찾은 각(°):", np.round(angles_xyz(R), 3))

# 1) 순서를 바꾸면 같은 세 숫자가 다른 자세가 된다
R_zyx = Rx(ang[0]) @ Ry(ang[1]) @ Rz(ang[2])
print("XYZ와 ZYX 행렬 원소 차이의 최댓값:", round(np.abs(R - R_zyx).max(), 3))

# 2) 각도의 시간미분 ≠ 각속도
t = np.linspace(0, 1, 2001); dt = t[1] - t[0]
a_t = np.radians(40 + 20*np.sin(2*np.pi*t))
b_t = np.radians(10 + 8*np.sin(2*np.pi*t + 1))
g_t = np.radians(-8 + 6*np.sin(2*np.pi*t + 2))
i = 700
Rm, Rp = cardan_xyz(a_t[i-1], b_t[i-1], g_t[i-1]), cardan_xyz(a_t[i+1], b_t[i+1], g_t[i+1])
Rdot = (Rp - Rm) / (2*dt)
Ri = cardan_xyz(a_t[i], b_t[i], g_t[i])
W = Ri @ Rdot.T                    # 원위 분절 축에서 본 각속도의 반대칭 행렬
w_true = np.array([W[2, 1], W[0, 2], W[1, 0]])
ad, bd, gd = [np.gradient(x, dt)[i] for x in (a_t, b_t, g_t)]
c2, s2 = np.cos(b_t[i]), np.sin(b_t[i]); c3, s3 = np.cos(g_t[i]), np.sin(g_t[i])
w_formula = np.array([c2*c3*ad + s3*bd, -c2*s3*ad + c3*bd, s2*ad + gd])
print("각도 변화율 (rad/s):     ", np.round([ad, bd, gd], 3))
print("각속도(회전행렬 차분):   ", np.round(w_true, 3))
print("각속도(변환식):          ", np.round(w_formula, 3))

# 3) gimbal lock: 둘째 각이 90°이면 첫째·셋째 각을 구분할 수 없다
for a, g in [(30, 0), (0, 30), (20, 10)]:
    Rg = cardan_xyz(np.radians(a), np.radians(90), np.radians(g))
    print(f"a={a:>3}°, g={g:>4}° → 행렬 첫 줄", np.round(Rg[0], 3), " 셋째 줄", np.round(Rg[2], 3))
```

과정 환경(Python 3.12, numpy 2.5)에서 실행한 출력:

```
되찾은 각(°): [40. 10. -8.]
XYZ와 ZYX 행렬 원소 차이의 최댓값: 0.141
각도 변화율 (rad/s):      [-1.289 -0.876 -0.323]
각속도(회전행렬 차분):    [-1.037 -1.143 -0.537]
각속도(변환식):           [-1.037 -1.143 -0.537]
a= 30°, g=   0° → 행렬 첫 줄 [ 0.     0.5   -0.866]  셋째 줄 [ 1. -0.  0.]
a=  0°, g=  30° → 행렬 첫 줄 [ 0.     0.5   -0.866]  셋째 줄 [1. 0. 0.]
a= 20°, g=  10° → 행렬 첫 줄 [ 0.     0.5   -0.866]  셋째 줄 [ 1. -0.  0.]
```

읽는 법: 각도 변화율 세 개와 실제 각속도 세 성분이 다릅니다. 변환식은 회전행렬 차분과 정확히 일치합니다. 마지막 세 줄은 둘째 각이 90°일 때 첫째·셋째 각의 합만 같으면(30 + 0 = 0 + 30 = 20 + 10) 같은 행렬이 된다는 것을 보여 줍니다. 그 자세에서는 두 각을 따로 정할 수 없습니다.

### 8. 정상 관절 운동 패턴을 phase로 읽기
수치는 Perry의 Rancho 3D 자료로, phase 대표값을 5° 단위로 반올림한 것입니다([P] 4–6장). 표 전체를 외우기보다 "어느 phase에 어느 방향으로 꺾이며, 그것이 어떤 과제를 위한 것인가"를 연결하세요.

| 관절 | 핵심 사건 (Perry, 평소 속도) | 기능적 의미 |
|---|---|---|
| 발목 (dorsiflexion +) | IC 중립 → LR 초 PF 약 5° → MSt·TSt 동안 DF, 45 % GC에 최대 약 10° → PSw에 빠르게 PF 약 15°까지 → swing에서 중립 근처 | LR의 PF = heel rocker, MSt–TSt의 DF = ankle·forefoot rocker 위의 경골 전진, PSw의 PF = toe rocker와 다리 비우기, swing의 중립 = 발끝 들기 |
| 무릎 (굴곡 +) | IC 약 5° → LR 끝(12 %) 약 20° → 39 % GC 최소 약 5° → PSw 끝(62 %) 약 40° → ISw에 최대 약 60° → TSw 끝 약 5° | LR 굴곡 = 충격 흡수(대퇴사두근 원심성), PSw–ISw 굴곡 = 발끝 들림 확보 |
| 고관절 (thigh 각, 굴곡 +) | IC 굴곡 약 20° → TSt 끝 신전 약 20° → swing 최대 굴곡 약 25° | stance 동안 신전 한 번, swing 동안 굴곡 한 번. 골반 기준 hip 각으로는 굴곡 약 30° ~ 신전 약 10° |

같은 패턴을 Whittle은 "무릎 굴곡 봉우리 둘(stance 10–20°, swing 60–70°)", "고관절은 swing 중간쯤 최대 굴곡 약 30°, 최대 신전은 OI 무렵 10–20°"로 요약합니다([W] 2장 pp.21–24). 숫자가 조금씩 다른 것은 피험자·속도·각 정의가 달라서입니다. Winter 교재 부록 A의 피험자(한 명)에서 부록 규약으로 계산하면 무릎 약 −3°–67°, 발목 약 −20.5°–+6.9°, 고관절 약 −6°–24°입니다(부록 A 자료로 이 코스에서 직접 계산한 값. 같은 자료의 공개본이 BMC의 `WinterTableA1.txt`입니다).

**속도가 패턴을 바꾼다.** LR의 무릎 굴곡은 90 m/min 대비 60 m/min에서 약 67 % 줄고 120 m/min에서 약 38 % 늘었습니다([P] 5장 Knee). 느린 환자의 "LR 무릎 굴곡 부족"이 병의 결과인지 속도의 결과인지 구분하려면 속도를 맞춘 정상 자료와 비교해야 합니다.

**같은 자세가 phase에 따라 정상이기도, 이상이기도 하다.** 무릎 굴곡 40°는 PSw 끝에서는 정상이지만 MSt에서는 이상입니다([P] 2장 도입). 각도 곡선은 늘 phase 표시와 함께 읽습니다.

## 흔한 오해
- **"대퇴 분절각 = 고관절각"** → 골반 기울기가 빠진 값입니다(thigh 각).
- **"교재의 발목 곡선이 위아래로 뒤집혀 있다 = 데이터가 다르다"** → 부호 규약이 다를 수 있습니다. 같은 책 안에서도 다릅니다.
- **"세 평면 영상 각을 모으면 3D 각"** → 투영각은 3D 각이 아닙니다.
- **"Cardan 각을 빼면 기준 자세 보정이 된다"** → 회전행렬 수준에서 보정해야 합니다([RM] 2장 p.57). 각은 벡터가 아니라 더하고 뺄 수 없습니다.
- **"자이로 값을 적분하면 굴곡·외전·회전 각이 나온다"** → 각속도와 각도 변화율은 다릅니다. 방향 추정은 회전 표현 위에서 적분합니다.
- **"무릎 내·외측 마커를 잇는 선이 굴곡축"** → LCS의 외측축은 장축에 직교하도록 다시 계산된 것이고, 마커를 조금만 잘못 붙여도 굴곡이 다른 각으로 새어 나갑니다([RM] 2장 p.41).

## 자기 점검

1. 생체역학식으로 무릎각이 175°입니다. 임상식으로는 대략 몇 도이고, 그 자세는?
<details><summary>정답</summary>완전히 편 무릎이 180° 근처이므로 약 5° 굴곡입니다. 정확한 변환은 그 연구가 0°를 어디에 두었는지 확인해야 합니다.</details>

2. Winter 교재 본문 식으로 계산한 발목각이 +15°입니다. 부록 A.4 규약으로는?
<details><summary>정답</summary>본문은 plantarflexion +, 부록은 dorsiflexion +이므로 −15°(plantarflexion 15°)입니다.</details>

3. thigh 각으로 TSt 끝에 신전 20°인데, 고관절 자체의 신전은 그보다 작습니다. 나머지는 무엇이 만드나요?
<details><summary>정답</summary>골반 전방경사 증가와 골반의 후방(외) 회전입니다. Perry는 이를 겉보기 과신전이라 부릅니다.</details>

4. 분절각 계산에 `np.arctan(dy/dx)`를 쓰면 어떤 문제가 생기나요?
<details><summary>정답</summary>x가 음수인 사분면에서 180° 틀리고, 분절이 수직에 가까우면 0으로 나누게 됩니다. `np.arctan2(dy, dx)`를 씁니다.</details>

5. x–y–z Cardan 순서에서 둘째 각이 90°에 가까워지면 무슨 일이 생기나요?
<details><summary>정답</summary>gimbal lock. 첫째와 셋째 회전축이 겹쳐 두 각을 따로 정할 수 없습니다(합만 정해짐). 둘째 각이 커질수록 해부학적 해석도 깨집니다.</details>

6. 같은 사람을 다른 날 다시 측정했더니 무릎 축 회전 곡선만 크게 달라졌습니다. 가장 먼저 의심할 것은?
<details><summary>정답</summary>마커 재부착에 따른 좌표계 차이와 연부조직 artifact입니다. 범위가 작은 각은 이런 오차의 비중이 커서 세션 간 재현성이 낮습니다.</details>

7. 60 m/min으로 걷는 환자의 LR 무릎 굴곡이 정상 자료(90 m/min)보다 작습니다. 바로 "충격 흡수 장애"라고 결론 내릴 수 있나요?
<details><summary>정답</summary>없습니다. 정상인도 느리게 걸으면 LR 무릎 굴곡이 크게 줄어듭니다. 속도를 맞춘 비교가 먼저입니다.</details>
