# R10 — Computer Simulation of Human Movement: 모델을 세우고, 운동방정식을 풀고, 결과를 조심해서 읽기

> **교재 노트** · 심화 파트 J — 생체역학 연구방법 · **교재:** [RM] 10장 pp.233–246 · **읽는 시간:** 40–50분 · **함께 읽기:** [T05 에너지와 동역학적 보행: 역진자 모델](../I-gait-theory/note-T05.md), [Day I6 실습](../I-gait/day-I6.md)

## 이 노트로 이해할 것
- 모델링이 "연구 질문 → 모델 → 실험과 비교 → 예측"을 되풀이하는 **과정**이고, 모델의 복잡도는 질문이 정한다는 것.
- 사람에게서 자료를 얻을 수 있는데도 시뮬레이션을 하는 이유.
- 자유물체도에서 자유도와 구속을 세고, 운동을 위치의 함수가 아닌 미분방정식으로 쓰는 이유.
- Lagrange 방정식의 세 항이 뜻하는 것과 Newton 제2법칙과의 관계.
- 수치 적분(Euler, Runge-Kutta)의 반복 구조, 시간 간격과 종료 조건을 고르는 법.
- 시뮬레이션 결과를 과하게 읽지 않기 위한 세 가지 해석 지침.

## 본문

### 1. 모델링은 과정이다
모델링에는 두 갈래가 있습니다. 실물을 닮은 축소 모형을 만드는 **물리 모델링**(모형 날개, 충돌 시험 인형, 동물 모델)과, 방정식을 세워 컴퓨터로 돌리는 **행동(behavioral) 또는 수학 모델링**입니다. 행동 모델은 부품 수를 줄여 여러 부분의 알짜 효과만 나타냅니다. 생체역학도 모든 뼈와 운동단위를 넣지 않고, 연구 질문에 답하는 데 필요한 만큼만 넣습니다([RM] p.233).

과정은 과학적 방법의 변형입니다([RM] 그림 10.1, p.234). 아래는 그 흐름을 이 노트에서 단계로 풀어 쓴 것입니다.

```
1. 연구 질문을 정한다
2. 역학 모델을 만들고 컴퓨터에 프로그램한다
3. 모델로 자료를 만들고, 대응하는 실험 자료를 모아, 둘을 비교한다
4. 맞지 않으면: 모델 자체의 문제인지 프로그램(수치)의 문제인지 가려 2로 돌아간다
5. 맞으면: 모델로 예측한다 → 예측이 타당하고 해석 가능한지 다시 묻는다
6. 새 이해와 새 질문 → 1
```

- **질문이 먼저입니다.** 모든 것을 담은 자전거 선수 모델은 없습니다. 오르막에서 체질량의 효과를 묻는다면 몸을 질점 하나로 두면 되고, 평지와 급경사에서 이관절근의 활성이 어떻게 달라지는지 묻는다면 여러 하지 분절과 근육이 있는 복잡한 모델이 필요합니다([RM] p.234).
- **평가에는 정해진 기준이 없습니다.** 3단계 비교(모델 자료, 실험 자료, 비교)를 하지만 저자들은 이것을 과학보다 기술(art)에 가깝다고 말합니다. 필요한 실험 자료도 3차원 운동학 전체일 때가 있고 최근 경기 기록이면 충분할 때도 있습니다([RM] pp.234–235).
- **타당성은 한 번에 정해지지 않습니다.** 달리는 사람을 튀는 공으로 본 모델(Cavagna 등 1977)은 20년 넘게 다시 논의되었습니다([RM] p.235).

| 모델 종류 | 구성 | 주로 쓰는 곳 |
|---|---|---|
| rigid-body | 강체 분절 + 관절 모멘트 | 가장 흔함 |
| mass-spring | 질량 하나 이상 + 스프링 | 달리기, 제자리 뛰기 등 반복 운동 |
| wobbling-mass, mass-spring-damper | 질량 + 스프링 + 감쇠기(dashpot) | 충격이 있는 운동 |
| musculoskeletal | 강체 분절 + 개별 근육 하위 모델 | 근육 수준의 질문 (9장, 11장) |

(분류는 [RM] p.235, 표는 이 노트에서 정리.)

### 2. 왜 시뮬레이션하는가
사람에게서 잰 자료가 가장 "진짜"인데 왜 인공 자료를 만들까요. 피험자는 매우 복잡하고 고유한 한계가 있기 때문입니다. 무작위로 변하고, 피로해지고, 힘과 협응에 한계가 있고, 안전과 윤리를 지켜야 합니다([RM] p.235). 교재의 예를 묶으면 다음과 같습니다([RM] pp.235–236).

- **조건이 많은 비교.** 점프나 사이클의 가장 좋은 자세를 찾으려면 자세마다 여러 번 재야 하는데, 피험자는 피로해지기 전 초반에, 그리고 평소 훈련하던 조건에서 가장 잘합니다.
- **가상 수술.** 경직이 있는 근육(예: 뇌성마비)의 길이를 늘이거나 부착부를 옮길 때, 얼마나 늘일지를 미리 예측해 시행착오를 줄입니다.
- **다치게 할 수 없는 실험.** 낙하산병은 최고 4.3 m 높이의 단에서 뛰어내리며 착지 훈련을 해 왔습니다. 배낭 무게와 바닥 종류별 안전 한계를 사람으로 정하려면 다치게 해야 하므로, 시뮬레이션으로만 가능합니다.
- **현실에서 못 만드는 조건.** 중력 상수(9.81 m/s²)를 키우거나 줄이기, 분절 질량 바꾸기.
- **변수 하나만 바꾸기.** 팔꿈치 신전근 힘만 키운 던지기. 사람이라면 훈련 중 다른 근육도 강해집니다. 몸통 질량이 지면반력에 주는 효과도 사람에서는 보행 속도, 보폭, 신발 기능의 변화와 섞입니다.
- **최적해 찾기.** 킥의 최적 동작, 체형별로 가장 경제적인 보행 박자, 체중·나이·보폭에 맞는 의족 발의 유연성.
- **이해의 시험.** 운동을 완전히 이해했다면 컴퓨터로 재현할 수 있을 것입니다. 모델이 예측에 실패하는 지점에서 새 이론이 나옵니다. 완벽하지 않은데도 강체 모델이 널리 쓰이는 이유입니다.

### 3. 일반 절차와 자유물체도
시뮬레이션은 운동 패턴(운동학)을, 경우에 따라 운동역학도 만들어 내는 프로그램입니다. 절차는 ① 역학 모델을 만들고 그림으로 그리기, ② 운동방정식 유도, ③ 수치 해 프로그램, ④ 시작·종료 조건 정하기, ⑤ 실행, ⑥ 해석과 실험 자료 비교입니다. 저자들은 이것도 가장 중요한 단계만 추린 단순화라고 밝힙니다([RM] p.236).

자유물체도(FBD)를 그리며 다섯 가지를 묻습니다([RM] p.236).

1. 계의 구성 요소는 몇 개인가?
2. 각 요소는 병진, 회전, 또는 둘 다 하는가?
3. 1차원, 2차원으로 되는가, 3차원이어야 하는가?
4. 각 요소의 위치를 정하는 데 좌표(자유도, DOF)가 몇 개 필요한가?
5. 좌표 수를 줄일 방법(구속, constraint)이 있는가?

```
운동방정식 수 = n(구성 요소) × k(요소당 자유도) − 구속이 줄여 주는 수
```

**Example 10.1(이중 진자, [RM] p.237).** 넙다리와 다리 두 분절이 평면에서 움직입니다. 2차원 분절은 질량중심의 (x, y)와 각도 하나, 곧 좌표 3개가 필요하므로 2 × 3 = 6개입니다. 그런데 다리는 무릎에서 넙다리에 붙어 있어야 하므로, 다리 질량중심의 위치는 넙다리 질량중심 위치·넙다리 각·다리 각의 함수입니다. 그래서 넙다리의 (x, y), 넙다리 각, 다리 각 **4개**면 계 전체를 기술합니다. 구속을 찾는 정해진 절차는 없고 예제로 익힙니다.

1차원 모델은 보행 박자, 달리기의 지면 충격, 다리의 변형, 내장이 호흡 패턴에 주는 영향 같은 문제에 쓰였습니다. 사람 운동은 여러 분절이 여러 방향으로 움직이므로 대부분 2차원이나 3차원이지만, 3차원 모델은 제어가 복잡해 덜 흔합니다. 다이빙·체조 같은 공중 동작(Yeadon 1993)과 골반의 3차원 운동을 넣은 보행 모델(Pandy와 Berme 1989)이 3차원으로 만들어진 예입니다([RM] p.236).

### 4. 왜 미분방정식인가
포물체의 궤적은 포물선, 단진자의 위치는 사인 함수처럼 단순한 계는 위치를 시간의 함수로 쓸 수 있습니다. 사람 운동에서는 그런 계가 드뭅니다. 그래서 위치 자체가 아니라 위치가 **어떻게 변하는지**를 씁니다. 분절의 운동을 바꾸는 모든 요인(근력, 관절력, 중력, 마찰)을 수식으로 표현해 미분방정식에 넣습니다([RM] p.237).

```
포물체 (Example 10.2, p.238)
  닫힌 해:      y = yo + vo·t + 0.5·g·t²
  미분방정식:   d²y/dt² = g ,  초기 조건 yo, vo   (두 번 적분하면 위 식)
```

분절 하나의 운동은 풀리는 경우가 많지만 그것도 sin θ ≈ θ 같은 단순화가 필요합니다. 두 분절(이중 진자)이 되면 분절끼리 상호작용해 손댈 수 없이 복잡해집니다([RM] p.237). Example 10.3(p.238)은 이중 진자 아래 분절(다리)의 각가속도 식을 보여 주는데, 무릎 모멘트 말고도 넙다리 운동에서 오는 두 항(넙다리 길이에 aT, 그리고 각속도 제곱 ωT²을 곱한 항), 고관절의 선운동 항(aHx, aHy; 본문은 "velocities"라 적지만 기호는 a입니다), 중력 항이 다리와 넙다리 각도의 삼각함수와 곱해져 들어갑니다. 이 식은 알려진 해석적 방법으로 풀 수 없어 위치의 식을 쓸 수 없습니다(Putnam 1991; Cappozzo 등 1975 참조). 이 노트에서는 식을 옮기지 않고 구조만 적습니다.

### 5. Lagrange 방정식으로 운동방정식 유도하기
단순한 계의 운동방정식은 그림을 보고 쓸 수 있지만, 다분절 계는 분절 간 상호작용 때문에 그렇게 되지 않습니다. 여러 고급 기법 가운데 Lagrange 방정식이 가장 많이 쓰이고, 힘 대신 계의 역학적 에너지에서 출발합니다([RM] 식 10.1, p.238).

```
d/dt(∂KE/∂Vi) − ∂KE/∂Yi + ∂PE/∂Yi = Fi          (병진, y 방향. x, z 방향도 같은 꼴)
d/dt(∂KE/∂ωi) − ∂KE/∂θi + ∂PE/∂θi = Mi          (회전, 식 10.8 p.239)
KE: 계 전체의 운동에너지,  PE: 위치에너지 (식 10.3의 쓰임 기준)
Vi, Yi: i번째 요소의 속도와 위치,  ωi, θi: 각속도와 각위치
Fi: 외력,  Mi: 그 분절에 작용하는 모멘트의 합
```

**Newton 법칙과 같은 내용입니다.** 중력과 바람 저항을 받는 낙하체 하나로 확인합니다([RM] 그림 10.2, 식 10.2–10.7, pp.238–239).

| 항 | 계산 | 결과 |
|---|---|---|
| 에너지 | KE = 0.5·m·v², PE = m·g·y | — |
| ∂PE/∂Y | m·g·y를 y로 미분 | m·g |
| ∂KE/∂Y | KE에 y가 없음 | 0 |
| d/dt(∂KE/∂V) | ∂KE/∂V = m·v, 시간 미분 | m·a |
| 합치기 | m·a − 0 + m·g = Fi | Fi − m·g = m·a |

Fi에 바람 저항 Fwind를 넣으면 FBD에 Newton 제2법칙을 적용한 식 Fwind − m·g = m·a와 같습니다.

- 가운데 항 ∂KE/∂Y는 요소가 하나인 계에서는 보통 0이고, 요소들이 서로 영향을 주는 다요소 계에서는 보통 0이 아닙니다. 그래서 **상호작용 항(interaction term)** 이라 부릅니다([RM] p.239).
- 사람 운동 시뮬레이션은 분절이 회전하므로 회전 꼴을 가장 많이 씁니다. M은 분절에 작용하는 모멘트의 합이고, 넙다리라면 고관절 모멘트에서 무릎 모멘트를 뺀 값입니다([RM] p.239).
- 좌표 선택에는 요령이 필요하지만, 일반적으로 분절마다 **각도 좌표**를 쓰고 계 전체의 가장 근위 또는 가장 원위 관절의 위치를 정하는 **직선 좌표 하나**를 둡니다([RM] p.239).

**Example 10.4(매달린 막대, [RM] p.239).** 물리 진자는 수직선 기준 각 θ 하나로 기술됩니다. 질량 m, 회전축 기준 관성모멘트 I, 축에서 질량중심까지 거리 d일 때 KE = 0.5·I·ω²이고, 회전 꼴의 세 항은 d/dt(∂KE/∂ω) = I·α, ∂KE/∂θ = 0, 그리고 PE를 θ로 미분한 중력 항입니다. 교재는 이 짧은 유도를 부록 G의 이중 진자 유도와 견주어 보라고 합니다. 이중 진자에서는 복잡도가 크게 늘고 ∂KE/∂θ 항이 0이 아니게 됩니다.

**추가 설명:** 교재는 이 예에서 PE = m·g·d·(1 − sin θ), ∂PE/∂θ = −m·g·d·cos θ로 적습니다. 각을 아래쪽 수직선에서 잰다면 흔히 쓰는 꼴은 PE = m·g·d·(1 − cos θ)이고, 이때 운동방정식은 익숙한 I·α = M − m·g·d·sin θ가 됩니다. 어느 쪽이든 유도 절차는 같으니, 직접 유도할 때는 각도의 기준선과 + 방향을 먼저 정하고 PE를 쓰세요.

### 6. 수치 해법: 조금 앞의 미래를 되풀이해 추정하기
모델 운동학을 만들어 내는 일을 "모델 방정식을 푼다"고 합니다. 본질은 외삽입니다. 시속 100 km로 달리면 200 km 떨어진 도시에 2시간 뒤 도착한다고 어림하는 것과 같습니다. 정확하지는 않고, 가까운 미래일수록 잘 맞습니다([RM] p.239, 그림 10.3 p.240).

```
초기 조건(각 분절의 위치·속도 = 계의 시작 에너지)
   → 미분방정식에 넣어 가속도 계산
   → 작은 시간 간격 뒤의 새 속도·위치 추정
   → 종료 조건을 만족했는가?  아니오 → 새 값을 넣어 반복 / 예 → 끝
```

(흐름은 [RM] 그림 10.4, p.240.) 이 과정을 forward simulation, forward solution, numerical integration이라 부릅니다([RM] p.240).

- **시작·종료 조건.** 시작 조건은 대체로 쉽습니다(보행이면 보행 주기 시작 시점의 분절 상태, 점프면 그럴듯한 시작 자세). 종료 조건은 어렵습니다. 시뮬레이션이 진행될수록 몸의 정확한 위치를 예측하기 어려워지기 때문입니다. 보행을 heel contact에서 끝내려 해도 swing 초기에 뒤꿈치가 바닥을 끌거나 발끝이 먼저 닿는 일이 생깁니다. 견고한 종료 알고리즘이 필요합니다([RM] p.240).
- **방법.** 가장 단순한 Euler 방법은 사람 운동 시뮬레이션에는 정밀도가 모자란 경우가 많습니다. Runge-Kutta 알고리즘은 4단계라 느리지만 더 정밀하고 널리 쓰입니다([RM] p.240).
- **시간 간격(Δt 또는 h).** 모델 식의 복잡도에 따라 다르지만 보통 0.01–0.001 s입니다. 너무 크면 여러 번 반복한 뒤 결과가 부정확해집니다. 줄이는 것은 대개 문제가 없지만 실행 시간이 지나치게 길어지지 않을 만큼은 커야 합니다([RM] p.242).

**Example 10.5–10.6(공기 저항이 있는 낙하, [RM] p.241).** 바람 저항을 속도의 함수로 쓴 운동방정식 F(v) − m·g = m·a를 가속도에 대해 풉니다.

```
a = F(v)/m − g
반복:  a 계산 → v = vo + a·Δt → h = ho + v·Δt + 0.5·a·Δt² → (ho, vo) ← (h, v)
교재 수치: F(v) = −0.2·v,  m = 10 kg,  ho = 100 m,  vo = 0,  Δt = 0.01 s,  h > 0인 동안 반복
```

| 반복 | F(v) (N) | a (m/s²) | v (m/s) | h (m) |
|---|---|---|---|---|
| 1 | 0 | −9.81 | −0.0981 | 99.99853 |
| 2 | 0.01962 | −9.80804 | −0.19618 | 99.99608 |

(교재가 계산한 10회 가운데 처음 2회만 옮겼고, 이 노트에서 다시 계산해 확인했습니다.) 저항 F(v)가 속도와 반대 부호라는 점, 그리고 0.01 s 동안 고작 1.5 mm, 다음 단계까지 3.9 mm 떨어질 만큼 한 걸음이 작다는 점을 봅니다. 사람 운동 시뮬레이션의 공통점은 **가속도의 미분방정식에서 출발**한다는 것입니다. 가속도를 알면 작은 시간 뒤의 속도 변화를, 이어서 위치 변화를 추정할 수 있고, 나머지는 반복입니다([RM] p.242).

**추가 설명:** 이 예의 위치 갱신은 이미 갱신한 속도에 0.5·a·Δt² 항을 한 번 더 더하는 꼴이라, 교과서적인 Euler 식(h = ho + vo·Δt)과 조금 다릅니다. 등가속도라면 첫 0.01 s의 실제 낙하 거리는 0.5 × 9.81 × 0.01² ≈ 0.49 mm입니다. Δt가 작으면 차이는 금방 묻히지만, 갱신 순서가 결과에 영향을 준다는 것은 기억해 둘 만합니다. 또 a = 0이 되는 종단 속도는 0.2·|v| = m·g에서 |v| = 98.1 / 0.2 = 490.5 m/s입니다.

다분절 계에서는 매 반복을 분절마다, 더 정교한 Runge-Kutta로 해야 해서 복잡하지만 원리는 같습니다. 이분절 진자의 식과 단계 전체는 부록 F에, 유도는 부록 G에 있습니다([RM] p.242, p.239).

**추가 설명:** 이 코스의 교재 검토에서 부록 F에 인쇄된 이중 진자 적분 식의 중력 항과 가속도 항에 부호 오류가 보고되어 있습니다(이 노트에서 따로 재검증하지는 않았습니다). 그래서 이 노트는 방법만 설명하고 부록 식을 옮기지 않습니다. 직접 구현할 때는 부록 G의 유도나 자신의 유도로 부호를 확인하세요.

### 7. 제어 이론
모델이 정교해질수록 힘과 모멘트를 어떻게 줄 것인가가 문제가 됩니다. 결국 몸이 스스로를 제어하는 방식을 모델링하게 되기 때문입니다. 제어 이론은 자연과 인공 시스템의 제어를 다루는 공학 분야이고, 교재는 그 복잡성과 시뮬레이션과의 접점을 알리는 정도로만 다룹니다([RM] p.242).

| 제어 방식 | 뜻 | 시뮬레이션에서 |
|---|---|---|
| closed-loop | 피드백(시각, 고유감각, 전정 등 자신과 환경에 대한 정보)을 받아 제어를 고침 | 구현이 어려움 |
| open-loop (feedforward) | 미리 짠 프로그램을 피드백 없이 실행 | 보통 이 방식: 제어를 미리 정하고, 돌려 보고, 끝난 뒤 고침 |

이 단순함이 비현실적으로 보여도, 완벽한 제어 없이 배울 것이 많습니다([RM] pp.242–243).

**Mochon과 McMahon(1980)의 ballistic walking([RM] p.242).** 곧고 단단한 지지 다리 하나가 흔들리는 넙다리와 다리를 받치는 3분절 모델이고, 머리·몸통·팔의 질량은 고관절의 질점 하나로 모았습니다. **근육이 없습니다.** 오른발 toe-off 순간에 시작해 오른발 heel contact에서 끝납니다. 사람 보행의 많은 특징을 예측하기에는 너무 단순하지만 저자들의 목표는 단순한 진술이었습니다. 모델은 넘어지지 않고 이동했고, 키가 커질 때 보행 속도가 달라지는 양상을 반영했으며, 사람처럼 swing 다리가 바닥을 피해야 한다는 조건이 속도를 제한했습니다. 역진자와 swing의 수동 역학은 [T05](../I-gait-theory/note-T05.md)에서 이어집니다.

### 8. 컴퓨터 모델의 한계와 해석 지침
아무리 정교해져도 한계가 남고, 그 원인은 다섯 가지입니다([RM] p.243).

1. **수치적 불완전성.** 오차는 대개 작고 해결할 수 있지만, 구성 요소가 늘수록 모델이 민감해지고, 초기의 작은 오차가 전파되어 끝에서는 측정 가능한 크기로 자랍니다. 매개변수 크기가 여러 자릿수씩 차이 나는 **stiff system**은 민감하고 일관성 없는 결과를 냅니다.
2. **충격 모델링의 어려움.** 충격은 분절 가속도를 급격히 바꿔 불연속과 수치 오차를 만들고, 강체 가정도 깹니다(걸을 때 발은 변형되며 에너지를 저장하고 흩뜨립니다). 시간 간격을 줄이거나(Derrick 등 2000은 0.0001 s) 모델을 더 복잡하게 해야 합니다. 그래도 여러 속도와 체형에 걸친 heel contact 모델링은 여전히 매우 어렵습니다.
3. **복잡한 구조의 근사.** 관절은 단순한 축이 아니고, 근육은 단순한 토크 발생기가 아니며, 분절은 강체가 아닙니다. 달리기 모델의 발목 모멘트가 어긋난다면 "발을 강체로 본 탓인가", "모델 발목이 실제 발목(거골하) 관절 축의 방향을 잘 근사했는가"부터 묻습니다([RM] p.244).
4. **사람의 적응력.** 거의 모든 보행 시뮬레이션은 평지에서 했고, 그 단순한 상황조차 완전히 모델링하지 못합니다. 운동을 **재현**하기는 대체로 쉽지만, 조건이 바뀔 때 운동이 어떻게 **달라질지 예측**하기는 어렵습니다. 정상 보행을 잘 재현하는 모델에 배낭만큼 몸통 질량을 더하면 보폭이 늘까요, 줄까요, 몸통 각은 바뀔까요([RM] p.244).
5. **가정의 불가피성.** 사람과 환경의 모든 요인을 넣을 수는 없습니다.

**Onyshko와 Winter(1980)([RM] p.243).** 몸통, 두 넙다리, 두 다리, 두 발의 7분절을 관절 모멘트 6개로 제어해 보행 주기 전체를 수행한 모델입니다. Lagrange 방법으로 유도한 운동방정식에는 인체계측 상수 22개와 수십 개의 항이 필요했고, 관절 모멘트는 실험 자료에서 가져왔습니다. 보행 시기에 따라 식이 달라져(오른발 단하지지, 왼발 단하지지, 양하지지) 사실상 네 개의 프로그램을, 지금 어느 시기인지 계속 판정하는 주 프로그램이 돌렸습니다.

**해석 지침 세 가지([RM] p.244).**
- 정량 자료의 **정확한 크기**는 보수적으로 다룹니다. 인체계측 추정, 필터링, 미분 때문에 관절 모멘트 자료의 해석 한계가 약 10 %인데, 모델은 여기에 가정을 더 얹습니다(다른 구속, 다른 최적화 기법, 다른 수치 적분법이면 값이 조금 달라질 수 있음).
- 모델 요소와 사람 구조 사이의 유추는 **느슨하게** 둡니다. 거의 모든 물리계는 2차 미분방정식으로, 거의 모든 사람 운동은 질량·스프링·감쇠기 조합으로 모델링할 수 있습니다. 그렇다고 몸의 어느 부분이 스프링**인** 것은 아니고, 모델 안에서 스프링**처럼** 거동하는 것입니다.
- "모델이 작동하는 방식이 곧 사람이 작동하는 방식"이라고 말하지 않습니다. 모델과 사람을 **따로** 논의합니다.

또 작은 관절 모멘트 차이보다 연구의 큰 결과를 보고, 해석은 그 모델의 조건 안에 머뭅니다. 정상 보행 모델로 절단자의 보행을 추론하지 않고, 한 속도의 결과를 모든 속도에 적용하지 않습니다. 시뮬레이션의 장점인 유연성과 통제 가능성이 바로 현실로 직접 추론할 수 없는 이유이며, 모든 결론은 추가 실험의 대상입니다([RM] p.244).

**Derrick, Caldwell, Hamill(2000)([RM] p.245).** 질량 하나가 스프링 위에서 튀는 mass-spring 모델은 뒤집힌 포물선 모양의 지면반력을 내지만, 사람의 수직 지면반력은 날카로운 첫 봉우리 뒤에 더 크고 둥근 봉우리가 옵니다. Alexander 등(1986)이 제안한 mass-spring-damper 모델(큰 질량 – 스프링 – 작은 질량 – 스프링과 감쇠기)은 두 봉우리를 만듭니다(그림 10.7). Derrick 등은 이 모델로 보폭의 영향을 보았습니다. 피험자 10명이 선호 보폭과 그 ±10 %, ±20 % 보폭으로 달렸고, 조건마다 최적화로 두 스프링의 강성을 조절해 모델 지면반력을 실험값에 맞췄습니다. 보폭이 줄면 실험의 충격 봉우리는 33 %, 지지 시간은 7 % 줄었습니다. 모델에서는 위 스프링이 짧은 보폭에서 긴 보폭의 2배로 뻣뻣했고, 아래 스프링은 반대로 약 80 % 수준이었습니다. 아래 질량은 체질량의 20 %로 지지 다리의 질량에 대응한다고 볼 수 있으므로, 위 스프링은 **몸 전체의 유연성** 척도로 읽습니다. 충격 흡수에는 여러 관절이 관여하므로 위 스프링을 무릎 같은 특정 관절의 강성이라 할 수 없습니다. 올바른 해석은 "보폭이 길어지면 몸이 더 유연해진다"입니다. 피험자가 무릎을 더 굽혀 유연성을 얻었다는 관찰은 있지만, 그것은 무릎이 없는 이 모델에서 나온 결론이 아닙니다.

### 9. 요약
한계가 많다고 해서 쓸모가 없는 것은 아닙니다. 우리는 걷기 같은 "단순한" 과제도 어떻게 수행하는지 완전히 알지 못하고, 시뮬레이션은 우리가 이해한 것을 시험하고 키우는 도구입니다. 모델을 만드는 일은 비교적 쉽습니다. 어려운 것은 해석의 한계를 지키는 일입니다([RM] pp.245–246).

| free-body diagram (FBD) | 자유물체도 | 요소에 작용하는 힘을 그린 그림. 운동방정식 유도의 출발점 |
| degree of freedom (DOF) | 자유도 | 요소의 위치를 정하는 데 필요한 좌표 수 |
| constraint | 구속 | 좌표 사이의 관계. 필요한 좌표와 식의 수를 줄임 |
| differential equation of motion | 운동 미분방정식 | 위치의 변화(가속도)를 힘·모멘트로 쓴 식 |
| Lagrange's equation | Lagrange 방정식 | 운동·위치에너지에서 운동방정식을 얻는 방법 |
| interaction term | 상호작용 항 | Lagrange 식의 가운데 항. 다요소 계에서 0이 아님 |
| initial / end conditions | 초기 / 종료 조건 | 적분을 시작하는 상태 / 멈추는 기준 |
| forward simulation (numerical integration) | 순방향 시뮬레이션(수치 적분) | 가속도 → 속도 → 위치를 시간 간격마다 반복 계산 |
| Euler method / Runge-Kutta | Euler 방법 / Runge-Kutta 알고리즘 | 가장 단순한 적분법 / 4단계의 더 정밀한 적분법 |
| time step (Δt, h) | 시간 간격 | 시뮬레이션 자료점 사이의 시간 |
| closed-loop / open-loop control | 폐루프 / 개루프(feedforward) 제어 | 피드백을 쓰는 제어 / 쓰지 않는 제어 |
| stiff system | 경직계 | 매개변수 크기가 여러 자릿수 차이 나 수치적으로 민감한 방정식계 |

## 흔한 오해
- **"더 자세한 모델이 더 좋은 모델이다"** → 필요한 복잡도는 연구 질문이 정합니다. 체질량의 효과는 질점 하나로 답할 수 있습니다([RM] p.234).
- **"시간 간격은 작을수록 무조건 좋다"** → 정확도 면에서는 대개 문제없지만 실행 시간이 늘어납니다. 보통 0.01–0.001 s에서 고릅니다([RM] p.242).
- **"실험 자료와 잘 맞으면 그 모델로 다른 조건도 예측할 수 있다"** → 재현과 예측은 다릅니다. 조건이 바뀌면 사람은 적응하고, 모델은 그 적응을 모릅니다([RM] p.244).
- **"모델의 스프링이 곧 다리다"** → 스프링처럼 거동한다고 말합니다. 모델에 없는 구조(무릎)에 대해서는 모델이 아무 말도 하지 못합니다([RM] pp.244–245).
- **"Lagrange 방정식은 Newton 법칙과 다른 물리다"** → 같은 내용의 더 일반적인 표현입니다. 낙하체에 적용하면 F = m·a가 그대로 나옵니다([RM] pp.238–239).
- **"시뮬레이션에서 나온 관절 모멘트의 5 % 차이는 의미가 있다"** → 실험 관절 모멘트의 해석 한계가 약 10 %이고, 모델은 가정이 더 많습니다([RM] p.244).

## 자기 점검

1. 같은 "자전거 타기"인데 질문에 따라 질점 모델과 다분절 근골격 모델을 고르게 되는 예를 설명해 보세요.
<details><summary>정답</summary>오르막에서 체질량이 미치는 효과를 묻는다면 몸을 질점 하나로 두면 충분합니다. 평지와 급경사에서 이관절근 활성이 어떻게 달라지는지 묻는다면 여러 하지 분절과 근육이 있는 모델이 필요합니다. 질문에 관련된 매개변수가 모델에 들어 있어야 하기 때문입니다.</details>

2. 평면 이중 진자에 좌표가 6개가 아니라 4개면 되는 이유는? 같은 논리로 넙다리–다리–발의 평면 3분절 사슬은 몇 개인가요?
<details><summary>정답</summary>분절 2개 × 좌표 3개 = 6개지만, 다리가 무릎에서 넙다리에 붙어 있다는 구속 때문에 다리 질량중심의 (x, y)는 독립이 아닙니다. 넙다리 (x, y), 넙다리 각, 다리 각 4개면 됩니다. 3분절 사슬은 3 × 3 = 9개에서 핀 관절 2개가 각각 2개씩 줄여 5개(근위 한 점의 (x, y)와 각도 3개)입니다. 3분절 계산은 교재의 논리를 이 노트에서 확장한 것입니다.</details>

3. (계산) Example 10.6의 갱신 규칙으로 직접 두 번 반복해 보세요. 가상의 값: m = 2 kg, F(v) = −0.5·v, Δt = 0.1 s, ho = 10 m, vo = 0, g = 9.81 m/s².
<details><summary>정답</summary>1회: F = 0, a = 0/2 − 9.81 = −9.81 m/s², v = 0 + (−9.81)(0.1) = −0.981 m/s, h = 10 + (−0.981)(0.1) + 0.5(−9.81)(0.1)² = 10 − 0.0981 − 0.04905 = 9.85285 m. 2회: F = −0.5 × (−0.981) = 0.4905 N, a = 0.4905/2 − 9.81 = −9.56475 m/s², v = −0.981 + (−9.56475)(0.1) = −1.937475 m/s, h = 9.85285 − 0.1937475 − 0.0478238 = 9.61128 m. 저항이 위쪽(+)으로 작용해 가속도 크기가 줄어드는 것을 확인합니다.</details>

4. (계산) 교재 예(m = 10 kg, F(v) = −0.2·v)에서 물체가 충분히 오래 떨어지면 속도는 어디로 수렴하나요?
<details><summary>정답</summary>a = F(v)/m − g = 0이 되는 속도입니다. −0.2·v = m·g = 98.1 N → v = −490.5 m/s. 크기 490.5 m/s에서 저항과 무게가 균형을 이룹니다. 교재에 나온 값이 아니라 식에서 계산한 것입니다.</details>

5. 낙하체에 Lagrange 방정식을 적용할 때 세 항이 각각 무엇이 되는지 쓰고, 가운데 항이 0인 이유를 말해 보세요.
<details><summary>정답</summary>d/dt(∂KE/∂V) = m·a, ∂KE/∂Y = 0, ∂PE/∂Y = m·g이므로 m·a − 0 + m·g = Fi, 곧 Fi − m·g = m·a입니다. KE = 0.5·m·v²에 위치 y가 들어 있지 않아 가운데 항이 0입니다. 요소가 여럿이면 한 요소의 운동에너지가 다른 요소의 위치(각도)에 의존하게 되어 이 항이 살아납니다.</details>

6. 보행 시뮬레이션을 "heel contact에서 종료"로만 정하면 어떤 문제가 생길 수 있나요?
<details><summary>정답</summary>시뮬레이션이 진행될수록 자세가 예상과 달라져, swing 초기에 뒤꿈치가 바닥에 끌리거나 발끝이 뒤꿈치보다 먼저 닿을 수 있습니다. 그러면 종료가 너무 일찍 일어나거나 아예 일어나지 않습니다. 이런 경우를 가려내는 견고한 종료 알고리즘이 필요합니다.</details>

7. Derrick 등의 모델에서 짧은 보폭일 때 위 스프링 강성이 2배였습니다. "짧은 보폭에서는 무릎 강성이 2배"라고 쓰면 왜 안 되나요?
<details><summary>정답</summary>모델에는 무릎이 없습니다. 위 스프링은 여러 관절이 함께 만드는 몸 전체의 유연성을 대표할 뿐이라 특정 관절에 대응시킬 수 없습니다. 쓸 수 있는 말은 "보폭이 길어지면 몸 전체가 더 유연하게 거동한다"까지입니다.</details>

8. 충격(예: 달리기의 heel contact)이 시뮬레이션에서 어려운 이유 두 가지와 대처 두 가지는?
<details><summary>정답</summary>이유: 가속도가 급변해 불연속과 수치 오차가 생기고, 발이 변형되며 에너지를 저장·소산하므로 강체 가정이 깨집니다. 대처: 시간 간격을 줄이거나(예: 0.0001 s), 모델을 더 복잡하게 만듭니다. 그래도 속도와 체형이 달라질 때의 heel contact는 여전히 어려운 문제입니다.</details>
