# R07 — Three-Dimensional Kinetics: 3D 역동역학, 모멘트 표현 좌표계, 유도 가속도 분석

## 이 노트로 이해할 것
- 3D 역동역학의 세 입력(분절 관성 특성, 운동학, 외력)과 Newton–Euler 식 6개가 분절 하나에서 푸는 것.
- force platform의 6개 신호에서 힘·COP·free moment 9개 값을 얻는 절차와 그때 넣는 가정.

- 유도 가속도 분석(IAA)이 "모멘트는 건너지 않는 관절도 가속시킨다"를 보여 주는 방식.

## 본문

### 1. 분절과 link model
평면 영상 여러 장에서 얻은 2D 힘·모멘트를 모은 것은 3D 분석이 아닙니다([RM] p.151). 이 장의 운동역학은 두 가정 위에 섭니다. ① 해부학적 분절은 강체이고, ② 강체들이 위계적 사슬로 이어져 link model을 이룹니다([RM] p.151).

분절은 **고정된 local coordinate system(LCS) + 고정된 관성 특성**(질량, 질량중심 위치, 주축 관성모멘트)만으로 정의됩니다. 분절 길이나 반지름은 관성 특성을 추정할 때만 쓰일 뿐 분절의 본질이 아니므로, 분절은 경계 없이 뻗은 "관성을 가진 좌표계"로 생각할 수 있습니다([RM] p.152). 관절은 회전 3·병진 3을 모두 허용하는 6자유도(six degrees of freedom) 모델이거나, 일부 자유도를 구속한 모델(2장의 global optimization)입니다. 어느 쪽이든 역동역학 계산은 같습니다([RM] p.152).

### 2. 3D 역동역학의 틀
힘을 주고 운동을 구하면 forward dynamics, 기록한 운동에서 힘·모멘트를 거꾸로 구하면 inverse dynamics입니다. 이 장은 Newton–Euler 방법을 씁니다([RM] p.152).

**부정정 문제.** [RM] 그림 7.2(p.153)는 발에 걸리는 근육·뼈 힘을 모두 그린 자유물체도입니다. 강체 하나의 식은 6개(병진 3, 회전 3)인데 미지수가 훨씬 많습니다. 그래서 모든 힘을 **관절 반력 벡터 하나(성분 3) + 알짜 관절 모멘트 벡터 하나(성분 3)**로 합칩니다([RM] pp.152–153). 근육이 관절면에 만드는 압축 하중은 이 방법으로 구할 수 없고, 계산된 관절 반력은 그 하중과 무관합니다. 관절 반력은 해부학적 관절이 실제로 받는 힘이 아닙니다([RM] p.153).

```
ΣF = d(m·v)/dt = m·a      (7.1, Newton: 힘의 합 = 운동량의 변화율)
Στ = d(I·ω)/dt            (7.2, Euler: 모멘트의 합 = 각운동량의 변화율)
```

입력은 세 묶음입니다([RM] p.153, 그림 7.4 p.154): 분절 관성 특성(m, I, 질량중심 위치), 운동학(v, a, ω, α), 지면반력 자료(F_grf, τ_grf, COP까지의 벡터).

```
절차 ([RM] p.154)
1. 분절 LCS 정의                          (2장)
2. 모션캡처 자료에서 모델의 pose 추정      (2장)
3. 인체계측을 피험자에 맞추고 관성 특성 결정
4. pose에서 각속도·각가속도 등 운동학 계산
5. 외력 기록과 표현
6. 관절 반력, 알짜 관절 모멘트, 관절 파워 계산
```

### 3. 분절 관성 특성
추정 방법에는 직접 측정, 사체 해부 기반 회귀식(Dempster 1955 등), 골격 기반 회귀식, 기하 도형 모델(Hanavan 1964 등)이 있습니다. 모두 추정이며, 대상 집단과 가설이 요구하는 정확도에 따라 고릅니다. 어느 것을 쓰든 역동역학의 개념과 계산은 같습니다([RM] p.155). 이 장의 하지 예는 질량에 Dempster, 관성모멘트에 Hanavan식 기하 도형을 씁니다([RM] p.155).

```
m_s = p_s·M                         (7.5)   p_s: 발 0.0145, 정강이(shank) 0.0465, 넙다리 0.1
r' = (0, 0, −c·L)                   (7.6)   LCS에서 본 질량중심
x = R_distal / R_proximal           (7.7)
c = (1 + 2x + 3x²) / (4(1 + x + x²))        (7.8, R_distal < R_proximal)
c = 1 − (1 + 2x + 3x²) / (4(1 + x + x²))    (7.9, R_proximal < R_distal)
```

- 모든 하지 분절을 균일 밀도의 **원뿔대(frustum of a right circular cone)**로 봅니다. 모수는 길이 L과 근위·원위 반지름입니다. 회귀식이 없는 분절이나 다른 종에도 쓸 수 있다는 것이 기하 접근의 장점입니다([RM] p.155, 그림 7.5 p.156).
- z축이 원위단에서 근위단을 향하므로, 근위단 원점에서 본 질량중심의 z 성분은 음수입니다([RM] p.155).
- **추가 설명(이 노트의 계산 예):** 체질량 70 kg이면 발 1.015 kg, 정강이 3.255 kg, 넙다리 7.0 kg입니다. x = 0.8인 분절은 c = (1 + 1.6 + 1.92)/(4 × 2.44) = 4.52/9.76 ≈ 0.463, 곧 질량중심이 근위단에서 길이의 약 46% 지점입니다. x = 1(원기둥)이면 c = 0.5입니다.

관성모멘트는 질량뿐 아니라 질량 분포에 좌우되며, 분절의 주축(이 장에서는 LCS 축)에 대해 정합니다. 긴 축(z)에 대칭인 원뿔대의 관성 텐서 I'는 LCS에서 대각 행렬입니다([RM] p.156).

```
I'xx = I'yy = a1·a2·M²/(δ·L) + b1·b2·M·L²      (7.11–7.12)
I'zz = 2·a1·a2·M²/(δ·L)                        (7.13)
δ  = 3M / (π·L·(R_p² + R_d·R_p + R_d²))         (밀도)
a1 = 9/(20π),  a2 = (1 + x + x² + x³ + x⁴)/(1 + x + x²)²
b1 = 3/80,     b2 = (1 + 4x + 10x² + 4x³ + x⁴)/(1 + x + x²)²     ([RM] p.157)
```

**추가 설명:** x = 1을 넣으면 I'zz = M·R²/2로 원기둥의 축 방향 관성모멘트와 같아집니다. 식을 옮겨 적은 뒤 이런 극한값으로 검산해 두면 좋습니다.

### 4. 운동학 계산
병진 운동학은 global coordinate system(GCS)에서 본 분절 질량중심의 위치·속도·가속도입니다([RM] p.157).

```
r_s,t = R'_s,t · r'_s + O_s,t                       (7.15)   LCS의 질량중심을 GCS로
v_s,t = (r_s,t+1 − r_s,t−1) / (2Δt)                 (7.16)
a_s,t = (r_s,t+1 − 2·r_s,t + r_s,t−1) / Δt²         (7.17)
```

각속도는 t − 1과 t + 1 시점의 회전 행렬 사이 변환에서 구하고(2장 식 2.74–2.76), 각가속도는 t − 1과 t + 1의 각속도를 유한 차분해 구합니다([RM] p.157).

### 5. 외력: force platform
근육은 분절 사이의 상대 회전을 만들지만, 몸 전체를 가속하려면 환경과의 상호작용이 필요합니다([RM] p.157). 보행에서 가장 큰, 흔히 유일하게 의미 있는 외력은 지면반력(GRF)입니다. 발–지면 접촉을 모델링하기보다 직접 기록하는 편이 대체로 더 정확하고 쉽습니다([RM] p.158).

- 신호는 force platform coordinate system(FCS)에서 얻습니다. 한 순간에 **한 분절(대개 한 발)만** 플랫폼에 닿아 있다고 가정합니다. 두 발이 한 판에 있으면 이 장의 역동역학은 성립하지 않습니다([RM] p.158).
- 채널 수는 기종마다 달라도 결국 독립 신호 6개, 곧 힘 F' = (F'x, F'y, F'z)와 모멘트 M' = (M'x, M'y, M'z)로 모입니다. 3D 역동역학에는 9개 값(힘 3, free moment 3, COP 3)이 필요하므로 가정으로 3개를 채웁니다([RM] p.158).

```
COP'z = 0                               (7.20)   걷는 면 = 플랫폼 윗면
COP'x = (Fx·dz − My) / Fz               (7.21)
COP'y = (Fy·dz + Mx) / Fz               (7.22)   dz: 전기적 원점에서 윗면 중심까지 거리
τ'z = M'z − COP'x·F'y − COP'y·F'x       (7.23, 교재 인쇄 그대로)
τ'x = τ'y = 0                           (7.24)
```

free moment는 발과 바닥 사이에서 수직축 둘레로 걸리는 토크입니다. 식 7.24는 피험자가 플랫폼을 붙잡거나 발이 달라붙어 판을 끌어올릴 수 없다는 가정입니다. 판 위에 손잡이나 커프를 달면 성립하지 않으며, 그때는 다른 측정 장치가 필요합니다. 이 가정들이 맞는지는 실험실마다 점검해야 합니다([RM] p.159). **추가 설명:** 식 7.21–7.23의 부호는 플랫폼의 축 방향 규약에 달려 있으므로, 실제 계산에서는 제조사 문서의 식과 대조합니다.

**FCS → GCS 변환([RM] pp.159–160).** 플랫폼 윗면 네 모서리 c1–c4의 GCS 좌표로 위치와 방향을 정합니다(모서리 순서는 제조사·기종이 정함).

```
O_FP = 0.25·(c1 + c2 + c3 + c4)        (7.25)   윗면 중심
i' = (c4 − c3) / |c4 − c3|             (7.26)   플랫폼 x축
v  = (c2 − c3) / |c2 − c3|             (7.27)   윗면 위의 또 다른 단위벡터
k' = i' × v                            (7.28)   면의 법선
j' = k' × i'                           (7.29)
R_FP = [i'; j'; k'] 를 행으로 쌓은 행렬   (7.30)   실험실 → 플랫폼
F = R'·F',   COP = R'·COP' + O,   τ = R'·τ'     (7.31–7.33)
```

이 절차는 플랫폼이 수평이거나 다른 판과 같은 평면일 것을 요구하지 않습니다. 원점을 더하는 것은 변위인 COP뿐입니다([RM] pp.159–160).

**검증([RM] p.160, 그림 7.7).** 양 끝이 뾰족하고 추적 표지 5개를 단 막대로 플랫폼을 눌러, 모멘트 없이 힘만 가합니다. 시스템이 올바르면 ① 카메라로 구한 막대 끝 위치와 플랫폼이 준 COP가 일치하고, ② 플랫폼이 잰 힘의 작용선(GRF에서 장치 무게를 뺀 것)이 막대 축 방향과 나란합니다. GRF 문제는 제조사 교정보다 **사용자가 소프트웨어에 넣은 플랫폼 설정값의 오류**인 경우가 많습니다. 수집 뒤에 고칠 수 있는 때가 많지만 항상은 아닙니다([RM] p.160).

### 6. 관절 반력과 알짜 관절 모멘트
마지막 가정: 관절 양쪽에서 반력끼리, 모멘트끼리 크기가 같고 방향이 반대입니다. 곧 관절이 일을 하지 않는다고 봅니다([RM] p.161).

**관절 반력([RM] p.161).** 첨자는 f = 발, l = 다리, a = 발목, k = 무릎, g = (0, 0, −9.81)입니다.

```
F_a = m_f·(a_f − g) − F_grf                    (7.37)
F_k = m_l·(a_l − g) + F_a                      (7.40)
F_j = Σ(s=1..m) m_s·(a_s − g) − F_grf          (7.42)   m: 관절보다 원위에 있는 분절 수
```

- 식 7.42의 합은 **어떤 순서로 더해도** 됩니다. 반드시 원위에서 근위로 풀 필요가 없고, 손가락 다섯 개처럼 가지가 갈라진 사슬에도 그대로 씁니다([RM] p.161).
- **닫힌 사슬은 풀 수 없습니다.** 보조기를 정강이와 넙다리에 단단히 붙여 무릎에 모멘트를 주면, 부착부에 힘 센서를 넣지 않는 한 피험자가 낸 무릎 모멘트를 구할 수 없습니다. 고관절 모멘트는 정강이와 보조기가 모두 고관절보다 원위이므로 구할 수 있습니다([RM] pp.161–162).
- **추가 설명(이 노트의 계산 예):** 정지한 발(m_f = 1.0 kg, a_f = 0)에 F_grf = (0, 0, 700) N이 걸리면 F_a = 1.0 × (0, 0, 9.81) − (0, 0, 700) = (0, 0, −690.19) N입니다.

**관절 모멘트([RM] pp.162–163).** 힘 하나가 만드는 모멘트는 τ = r × F(7.43)이고, 세 항을 모두 같은 좌표계로 분해해야 합니다.

```
관성 항 (분절 LCS에서 계산한 뒤 GCS로 되돌림)
ω'_s = R_s·ω_s,   α'_s = R_s·α_s                        (7.44–7.45)
τ'I_s = I'_s·α'_s + ω'_s × (I'_s·ω'_s)                  (7.46)
τI_s  = R'_s·τ'I_s                                      (7.47)

발목: τ_a = τI_f − τ_grf − (r_a.grf × F_grf) + r_a.f × m_f·(a_f − g)                  (7.53)
일반: τ_j = Σ(s=1..m) [τI_s + r_j.s × m_s·(a_s − g)] − τ_grf − (r_j.grf × F_grf)      (7.61)
```

- 관성모멘트 I'는 분절 LCS에서는 일정하지만 GCS에서는 분절이 움직이므로 일정하지 않습니다. 그래서 관성 항만 LCS에서 계산합니다([RM] p.162).
- r_j.s는 관절에서 분절 s의 질량중심까지, r_j.grf는 관절에서 COP까지의 벡터입니다. 식 7.61도 순서와 무관하게 더할 수 있습니다([RM] p.163).

**용어와 부호([RM] pp.163–164).**
- 이렇게 구한 것이 근육과 다른 조직이 내는 **internal moment**입니다. 지면반력이 만드는 **external moment**는 크기가 같고 부호가 반대입니다.
- **support moment**는 고관절·무릎·발목 신전 모멘트의 합입니다. 세 관절의 신전을 같은 부호로 맞춰야 합이 의미가 있으므로, 오른손 법칙으로 정한 값 중 시상면 무릎 모멘트에 −1을 곱합니다.
- 교재의 권고: 좌표계 정의(y-up, z-up)에 흔들리지 않도록 해부학 용어(굴곡/신전, 외전/내전, 축 회전)로 보고하고, 그래프 축에 부호가 가리키는 방향을 적습니다.

### 7. 모멘트를 어느 좌표계로 보여 줄 것인가
관절 반력과 모멘트는 GCS에서 계산되지만 보고할 때는 해부학적으로 의미 있는 좌표계로 분해합니다. **표준은 없습니다**([RM] p.164). GCS에 그대로 두는 방식은 진행 방향이 GCS의 한 평면과 나란하다는 2D 중심 관점이라 시상면 외의 두 성분을 해석하기 어렵습니다. 저자들은 이 표현을 쓰지 말라고 권합니다([RM] p.164).

| 선택지 | 분해 좌표계 | 성질 | 주의 |
|---|---|---|---|
| 1 | 근위 분절 LCS | 직교, 벡터 | 각속도·각가속도·관절 힘과는 일관, JCS 관절각과는 불일치 |
| 2 | 원위 분절 LCS | 직교, 벡터 | 1과 같음 |
| 3 | joint coordinate system(JCS) | 비직교, 벡터 아님 | 관절각과 일관(임상 보행분석에서 인기). 성분을 더할 수 없어 support moment 계산 불가 |
| 4 | plane of progression(PoP) | ad hoc 투영 | 어떤 운동학 변수와도 일관되지 않음 |

(내용: [RM] p.164, 그림 7.9 p.166. 표는 이 노트를 위해 정리한 것입니다.)

- 네 가지 모두 수학적으로 타당하고 맥락에 따라 장점이 있으나 결과가 크게 다를 수 있습니다. 저자들은 특정 선택지를 지지하지 않습니다. 논문이 분해 좌표계를 밝히는 일이 드물어 문헌의 모멘트 자료 상당수가 의심스럽다고 봅니다([RM] p.164).
- 비교는 **같은 종류끼리만** 합니다(벡터는 벡터와, 비직교 표현은 같은 비직교 표현과)([RM] p.164).
- [RM] 그림 7.8(p.165)은 13명의 보행 한 주기 평균 ± 1 표준편차를 고관절·무릎·발목의 세 성분으로 보여 줍니다. 근위 분절 좌표계로 분해했고 단위는 N·m/(BW·LL), 굴곡·내전·내회전이 양(+)입니다.
- **정규화.** 피험자 간 차이를 줄이려는 것으로, 체질량(N·m/kg) 또는 체중 × 다리 길이(N·m/(BW·LL))로 나누는 방식이 가장 많이 보고됩니다. 한 사람의 임상 보고서라면 꼭 필요하지 않을 수 있습니다([RM] p.165).

**Brandon and Deluzio(2011) 상자([RM] pp.166–167).** 무릎 골관절염 환자와 대조군의 external 3D 모멘트를 네 좌표계로 각각 표현하고 주성분분석으로 특징을 뽑았습니다. 모든 관절 모멘트의 크기와 모양이 좌표계마다 달랐습니다. 그래도 좌표계와 무관하게 유지된 환자군 특징이 넷 있었습니다: 고관절 내전 모멘트 감소, 무릎 내전 모멘트 증가, 무릎 내회전 모멘트 진폭 감소, 초기 stance 발목 내전 모멘트 증가. 반대로 고관절 굴곡 모멘트의 군 차이는 근위(골반) 좌표계에서만 유의했고 PoP(P = .07)와 원위 좌표계(P = .83)에서는 아니었습니다. 좌표계 선택은 피험자마다 모멘트에 다르게 작용할 수 있습니다.

### 8. 3D 관절 파워
관절 파워는 근육이 계에 에너지를 더하거나 빼는 일률입니다. 양이면 에너지를 더하고(구심성 수축처럼), 음이면 뺍니다(원심성 수축처럼)([RM] p.168).

```
P_j = P_proximal + P_distal                           (7.62)
P_j = τ_j · (ω_proximal − ω_distal) = τ_j · ω_j       (7.65)   관절에 병진이 없다고 볼 때
P_j = τ_j · ω_j + F_j · Δv                            (7.67)   6자유도 관절, Δv: 관절 양쪽 병진 속도의 차
τ_ICR = τ_j + (r × F_j),   Δv = ω_j × r               (7.68, 7.70)
P_j = τ_ICR · ω_j                                     (7.72)
```

- 3D에서는 모멘트 벡터와 관절 각속도 벡터의 **내적**입니다. 식 7.65의 "병진 없음"은 6자유도 관절에는 지나친 가정입니다([RM] p.169).
- r은 순간 회전 중심(instant center of rotation, ICR)에서 관절 중심으로 가는 벡터입니다. 병진 속도 차를 반영한 관절 파워는 ICR 둘레로 계산한 파워와 같습니다(Buczek 등 1994; [RM] p.169, 그림 7.11 p.168).

**Allard 등(1996) 상자([RM] p.170).** 1.30 m/s 보행의 연속 두 stride에서 좌우 하지의 파워를 세 평면으로 비교했습니다. stance 비율은 좌우 차이가 없었고, 파워 차이는 주로 시상면의 흡수 구간에 있었으며 저자들은 비대칭이 아니라 보행 조정으로 해석했습니다. 총 양의 일은 같았고 총 음의 일은 오른쪽이 유의하게 컸습니다.

### 9. 알짜 모멘트의 해석: induced acceleration과 induced power
역동역학 결과는 흔히 정상 패턴과의 차이를 찾는 방식으로 해석됩니다. 차이는 찾아내지만 **원인**은 거의 설명하지 못합니다. 힘·모멘트와 그 결과인 운동 궤적 사이의 인과를 추론하기가 매우 어렵기 때문입니다([RM] p.169).

**반례 모델([RM] pp.169–171, 그림 7.13–7.14).** 발을 바닥에 고정하고 정강이·넙다리·HAT(머리–팔–몸통) 세 링크와 soleus, gastrocnemius만 둔 평면 모델입니다. 두 근육이 수축하면 무릎은 10° 굴곡에서 완전 신전으로 가는데, 무릎 모멘트는 굴곡 모멘트만 내는 gastrocnemius에서 나옵니다. 고관절을 건너는 근육이 없는데도 고관절은 더 굽습니다. 역동역학만으로는 이 결과를 설명할 수 없습니다.

**Induced acceleration analysis(IAA).** 입력 토크 **하나**가 각 일반화 좌표에 만드는 순간 가속도를 계산합니다([RM] p.171). 2분절 평면 진자를 예로, Newton–Euler 식 6개를 자세를 정하는 최소 변수(일반화 좌표 θ1, θ2)만 남긴 식 2개로 줄입니다([RM] pp.172–173, 그림 7.15).

```
τ = M(q)·q̈ + C(q, q̇) + G        (7.84)   q = (θ1, θ2)
```

M은 관성 행렬(질량과 관성모멘트가 섞여 있어 I라 쓰지 않음), C는 속도 관련 항, G는 중력과 외력 항입니다. 이 식을 q̈에 대해 풀면 각 항에 M⁻¹이 곱해집니다(7.85)([RM] p.173). **추가 설명:** 교재 식 7.85는 C 항 앞 부호가 +로 인쇄되어 있는데, 식 7.84를 그대로 풀면 q̈ = M⁻¹(τ − C − G)입니다.

M⁻¹에서 나오는 두 원리([RM] p.173):
1. M⁻¹은 항상 모든 원소가 차 있으므로, **한 관절의 모멘트는 그 관절뿐 아니라 몸의 모든 관절을 가속**합니다.
2. M⁻¹의 원소에 관절각이 들어 있으므로, 같은 모멘트라도 **자세에 따라** 가속의 크기가 달라지고 방향까지 바뀔 수 있습니다. 달리기 midstance의 발목 족저굴곡근은 대체로 무릎을 펴는 쪽으로 작용하지만, toe-off에 가까워져 무릎과 고관절이 더 굽으면 무릎을 굽히는 쪽으로 작용할 수 있습니다.

IAA는 forward dynamics(예측)와 inverse dynamics(기술)의 중간에 놓여, 실험 자료와 시뮬레이션 자료 모두의 해석에 쓰입니다. 이름은 Zajac and Gordon(1989)이 붙였습니다([RM] p.173). 근육군 기능을 잃은 환자는 다른 근육이 건너지 않는 관절을 가속하는 능력에 기대어 보상 전략을 만듭니다([RM] p.173).

**Induced power analysis([RM] pp.174–175).** 알짜 모멘트는 분절 간 반력을 통해 자신이 직접 작용하지 않는 분절의 파워에도 기여합니다. 분절 파워가 양이면 그 모멘트가 분절을 가속하고, 음이면 감속합니다. Neptune 등(2001)은 push-off에서 발목 근육이 몸통 지지와 전방 진행에 크게 기여하며, 단관절근 soleus와 이관절근 gastrocnemius가 다리와 몸통에 파워를 나누는 방향이 서로 반대임을 보였습니다([RM] 그림 7.16, p.175). 교재는 이 기법이 임상 동작분석 분야에서 논쟁적이었다고 함께 적습니다([RM] p.174).

**Siegel, Kepple, and Stanhope(2007) 상자([RM] p.174).** 특발성 염증성 근병증 여성 3명과 건강한 1명을 비교한 사례 연구입니다. 정상 보행에서는 midstance 이후 족저굴곡근이 지지와 전진을 만들면서 고관절을 신전 쪽으로 가속하고, 고관절 굴곡근이 원심성으로 이를 버팁니다. 굴곡근이 약한 환자들은 자세와 근육 사용을 바꿨습니다. 한 명은 무릎을 더 굽혀 족저굴곡근의 고관절 신전 효과를 줄였고, 두 명은 무릎 굴곡 모멘트나 중력으로 전진을 만들었습니다. 독립 보행은 가능했지만 속도는 느렸습니다. Siegel 등(2004)은 에너지 효과가 반대인 모멘트 쌍(무릎 신전근 대 중력, 고관절 굴곡근 대 족저굴곡근)이 함께 작용해 분절 사이 에너지 흐름의 균형을 맞춘다고 보고했습니다([RM] p.175).

### 10. 오차의 출처
- **GRF.** FCS 안의 값은 세 자료 중 가장 정확하고 믿을 만합니다. 약한 고리는 FCS → GCS 변환에 쓰는 설정값의 사용자 오류입니다([RM] p.175).
- **관성 특성.** 추정 기법에 따라 값이 크게 달라도 최종 결과에는 크게 기여하지 않습니다(적어도 보행에서는)([RM] p.175).
- **운동학.** 관절 모멘트는 pose 추정의 정확도에 크게 의존하고, pose 추정은 연부조직 움직임(soft tissue artifact)에 민감합니다([RM] p.175).
- **강체 가정.** 다리 분절에는 어느 정도 타당하지만 발과 넙다리에는 그렇지 않습니다. 발을 몇 개의 분절로 나누든 발목의 운동역학은 같으므로, 발 자체가 연구 대상이 아니면 나눠서 얻는 것이 없습니다. 넙다리에는 wobbling mass 모델이 쓰이기도 하지만, 걷기·달리기에서 그 이득이 연부조직 오차를 보상하는 것 이상인지는 의문입니다([RM] p.175).

요약하면 3D 분석은 외력, 표지의 3D 좌표, 분절 인체계측의 세 자료를 합치는 일이고 각 자료의 오차를 함께 고려해야 합니다. 가장 흔한 보고 좌표계는 근위 분절 좌표계입니다([RM] pp.175–176).

## 흔한 오해
- **"여러 평면의 2D 모멘트를 모으면 3D 분석이다"** → 아닙니다. 3D 벡터로 계산한 뒤 좌표계로 분해해야 합니다([RM] p.151).
- **"관절 반력이 곧 관절이 받는 하중이다"** → 근육이 만드는 압축 하중이 빠져 있고, 이 방법으로는 구할 수 없습니다([RM] p.153).
- **"역동역학은 반드시 발에서부터 차례로 풀어야 한다"** → 일반식 7.42와 7.61은 원위 분절들을 어떤 순서로 더해도 됩니다([RM] pp.161, 163).
- **"무릎 내전 모멘트는 어느 논문에서나 같은 양이다"** → 분해 좌표계, internal/external, 정규화가 다르면 값과 통계 결론이 달라집니다([RM] pp.164–167).
- **"JCS 성분도 더해서 support moment를 만들 수 있다"** → JCS는 비직교라 성분이 벡터가 아닙니다([RM] p.164).
- **"근육은 자신이 건너는 관절만 움직인다"** → 한 관절의 모멘트는 모든 관절을 가속하고, 그 효과는 자세에 따라 달라집니다([RM] p.173).

## 자기 점검

1. (계산) 체질량 80 kg인 사람의 발, 정강이, 넙다리 질량을 식 7.5로 구하세요.
<details><summary>정답</summary>발 80 × 0.0145 = 1.16 kg, 정강이 80 × 0.0465 = 3.72 kg, 넙다리 80 × 0.1 = 8.0 kg.</details>

2. (계산) FCS에서 Fx = 50 N, Fy = −20 N, Fz = 800 N, Mx = 24 N·m, My = −40 N·m, dz = 0.04 m입니다. 식 7.21–7.22로 COP를 구하세요.
<details><summary>정답</summary>COP'x = (50 × 0.04 − (−40)) / 800 = 42 / 800 = 0.0525 m. COP'y = (−20 × 0.04 + 24) / 800 = 23.2 / 800 = 0.029 m. COP'z = 0. 이 값은 FCS 기준이므로 GCS로 옮길 때 회전시킨 뒤 플랫폼 원점을 더합니다.</details>

3. (계산) 질량중심의 한 좌표가 연속 세 프레임에서 0.100, 0.112, 0.130 m이고 Δt = 0.01 s입니다. 가운데 프레임의 속도와 가속도는?
<details><summary>정답</summary>v = (0.130 − 0.100) / (2 × 0.01) = 1.5 m/s. a = (0.130 − 2 × 0.112 + 0.100) / 0.01² = 0.006 / 0.0001 = 60 m/s².</details>

4. (계산) 같은 좌표계로 표현한 τ_j = (60, 5, −2) N·m, ω_j = (3, 0.5, 1) rad/s일 때 관절 파워는?
<details><summary>정답</summary>P = 60 × 3 + 5 × 0.5 + (−2) × 1 = 180 + 2.5 − 2 = 180.5 W. 양이므로 에너지를 더하는 쪽입니다.</details>

5. force platform 계산에서 τ'x = τ'y = 0으로 두는 근거와, 이 가정이 깨지는 상황은?
<details><summary>정답</summary>피험자가 플랫폼을 붙잡아 끌어올릴 수 없다는 가정입니다. 플랫폼에 손잡이나 커프를 달면 성립하지 않고, 다른 측정 장치로 9개 값 중 일부를 직접 재야 합니다([RM] p.159).</details>

6. 무릎 보조기를 찬 사람에서 고관절 모멘트는 구할 수 있지만 "사람이 낸" 무릎 모멘트는 구할 수 없는 이유는?
<details><summary>정답</summary>보조기가 정강이와 넙다리에 함께 고정되면 무릎에서 닫힌 사슬이 되어, 부착부의 힘을 재지 않으면 사람과 보조기의 몫을 나눌 수 없습니다. 고관절에서는 정강이와 보조기가 모두 원위에 있어 한 덩어리로 계산됩니다([RM] pp.161–162).</details>

7. 한 연구는 고관절 굴곡 모멘트의 군 차이가 유의하다고 하고 다른 연구는 아니라고 합니다. 방법 절에서 먼저 볼 것은?
<details><summary>정답</summary>모멘트를 분해한 좌표계입니다. Brandon and Deluzio(2011)에서 이 차이는 근위(골반) 좌표계에서만 유의했습니다. internal/external 여부와 정규화 방식도 함께 확인합니다([RM] pp.164–167).</details>

8. 식 7.84에서 M⁻¹이 "모두 차 있고 자세에 의존한다"는 사실이 뜻하는 두 가지는?
<details><summary>정답</summary>한 관절의 모멘트가 모든 관절을 가속한다는 것, 그리고 같은 모멘트라도 자세가 바뀌면 가속의 크기와 방향이 달라질 수 있다는 것입니다([RM] p.173).</details>
