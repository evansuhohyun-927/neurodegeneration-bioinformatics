# 심화 파트 J — 생체역학 연구방법: 교재 노트 목록

> **교재 노트** · 심화 파트 J — 생체역학 연구방법 · 노트 16편 · 노트당 읽는 시간 40–60분 · 첫 노트: [R00](note-R00.md)

이 폴더는 교재 한 권을 **장 순서대로** 따라가는 학습 노트입니다. 교재는 Robertson DGE, Caldwell GE, Hamill J, Kamen G, Whittlesey SN. *Research Methods in Biomechanics*. 2nd ed. Human Kinetics; 2014이고, 이 저장소에서는 **[RM]** 으로 줄여 부릅니다.

[보행분석 이론 노트(T01–T12)](../I-gait-theory/index.md)는 주제별로 교재 여러 권을 비교합니다. 이 폴더의 R 노트는 반대로 [RM] 한 권의 모든 절을 빠짐없이 따라갑니다. 보행 연구실에서 쓰는 측정·계산 방법(운동학, 역동역학, EMG, 근골격 모델, 신호처리)을 처음부터 끝까지 한 번 훑고 싶을 때 씁니다.

- 모든 노트는 같은 틀입니다: 이 노트로 이해할 것 → 영상 → 핵심 질문 → **교재 절 지도** → 본문 → 주요 용어 → 흔한 오해 → 자기 점검 → 더 읽을거리.
- **교재 절 지도**는 그 장의 실제 절 제목과 쪽을 원문 그대로 적은 표입니다. 책을 펴 놓고 어디를 읽는 중인지 맞춰 볼 수 있습니다.
- 쪽은 모두 **인쇄 쪽**입니다. 본문의 `([RM] p.137)`은 책 137쪽을 가리킵니다.
- `**추가 설명:**`으로 시작하는 문단은 교재에 없는 보충입니다. 그 표시가 없는 내용은 교재에서 왔습니다.
- 노트는 교재를 대신하지 않습니다. 교재의 문장·그림·표·연습문제는 옮기지 않았고, 그림과 표는 번호와 쪽으로만 가리킵니다. 교재 본문은 이 저장소에 없습니다.

## 읽는 순서

**처음부터 끝까지(4주, 주 4편).** 교재의 Part 순서를 따르되, 미분과 필터를 먼저 알아야 1장의 속도·가속도 계산을 믿을 수 있으므로 R12를 앞으로 당깁니다.

| 주 | 노트 | 묶는 이유 |
|---|---|---|
| 1주 | R00 → R15(단위·벡터·행렬만) → R01 → R12 | 측정한 좌표를 미분하고 걸러 내는 데까지 |
| 2주 | R02 → R03 → R04 → R05 | 3D 좌표계, 분절 변수, 힘 측정, 평면 역동역학 |
| 3주 | R06 → R07 → R08 → R09 | 에너지·파워, 3D 운동역학, EMG, 근육 모델 |
| 4주 | R10 → R11 → R13 → R14 | 시뮬레이션, 근골격 모델, 협응, 파형 분석 |

**급할 때(6편).** R01, R04, R05, R08, R12, R06. 마커 좌표와 지면반력에서 관절 모멘트·파워를 구하고 EMG를 함께 읽는 데 필요한 최소한입니다.

## 읽을 때 지킬 것

- **부호와 좌표계는 장마다 다시 확인합니다.** 같은 책 안에서도 2D 장과 3D 장의 축 규약이 다릅니다.
- **식은 가정과 함께 읽습니다.** 강체 분절, 마찰 없는 핀 관절, 분절 변수의 추정 오차 같은 가정이 깨지는 곳에서 결과도 깨집니다.
- **숫자는 교재의 조건이 붙은 숫자입니다.** 노트의 수치에는 쪽을 달았습니다. 다른 조건에 그대로 쓰지 않습니다.
