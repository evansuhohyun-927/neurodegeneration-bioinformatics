## 개념 설명

### 왜 정규화가 필요한가, 그리고 무엇에 맞추는가

한 사람만 보는 연구(예: 수술 전 언어 영역 지도)라면 그 사람의 공간에서 분석하면 됩니다. 하지만 "사람의 뇌에서는"이라고 말하려면 여러 사람의 자료를 같은 자리끼리 겹쳐야 합니다. 큰 구조(반구, 뇌량, 중심고랑)는 누구에게나 있지만 크기와 모양, 고랑의 세부는 사람마다 크게 다릅니다. 각자의 뇌를 공통 좌표 공간으로 변형하는 일을 **공간 정규화**(spatial normalization)라 합니다.

**아틀라스**(atlas)는 좌표 공간 위의 해부학 지도이고, **템플릿**(template)은 그 공간을 대표하는 영상, 즉 맞춰 넣을 목표입니다. 초창기의 Talairach 공간은 한 사람의 사후 뇌와 해부학 표지점(앞·뒤맞교차 등)으로 정의되어 MRI 템플릿이 없었습니다. 지금 표준은 많은 사람의 MRI를 평균해 만든 **MNI 템플릿**(MNI305, ICBM152 계열)입니다. 같은 "MNI"라도 판에 따라 크기와 위치가 조금씩 다르므로, 논문에는 어떤 템플릿을 어떤 도구로 썼는지 정확히 적어야 합니다.

### 구조 영상 전처리와 여러 단계 정합

T1 강조 구조 영상은 기능 영상보다 해부학이 선명해서 정규화의 다리 역할을 합니다. 먼저 몇 가지를 손봅니다. 고자장에서 생기는 넓고 느린 밝기 얼룩을 고치는 **bias field 보정**, 두피와 두개골을 떼어 내는 **뇌 추출**(skull stripping), 회백질·백질·뇌척수액으로 나누는 **조직 분할**(segmentation)입니다. 분할은 생각보다 어렵습니다. 잡음 때문에 조직별 밝기 분포가 겹치고, 한 voxel 안에 여러 조직이 섞이는 **부분 용적 효과**(partial volume effect)가 있기 때문입니다. 그래서 "이 위치는 원래 회백질일 확률이 높다"는 사전 확률 지도를 함께 쓰는 방법이 널리 쓰입니다.

정합은 보통 여러 단계로 합니다. 기능 영상 → (같은 슬라이스로 찍은 구조 영상) → 고해상도 구조 영상 → 템플릿 순서로 각각 변환을 구한 뒤, 이 변환들을 **하나로 합쳐** 기능 영상을 한 번만 다시 그립니다. 보간할 때마다 영상이 번지기 때문입니다(예시 1). 기능 영상을 바로 EPI 템플릿에 맞추는 방법도 있지만, 기능 영상은 내부 해부학이 흐려 뇌 윤곽만 맞고 속 구조는 덜 맞을 수 있습니다.

정규화를 통계 분석 **전에** 하는 흐름(SPM에서 흔함)과 각자 공간에서 통계를 낸 뒤 결과 지도만 옮기는 흐름(FSL에서 흔함)이 있고, 둘 다 타당합니다. 뒤의 방식은 저장 공간을 아끼지만, 뇌 밖이 NaN으로 채워진 영상을 보간하면 가장자리까지 NaN이 번지는 문제가 있어 0으로 바꿔 두어야 합니다.

### 서로 다른 대비를 맞추는 비용 함수, 선형과 비선형

같은 종류의 영상끼리(예: 움직임 보정) 맞출 때는 밝기 차이의 제곱합이나 상관이 잘 듣습니다. 하지만 T1 영상에서는 백질이 밝고 회백질이 어둡고, T2 계열에서는 반대입니다. 이런 **서로 다른 대비**(between-modality)의 영상에서는 "같은 곳은 같은 밝기"라는 가정이 깨집니다. 이때 쓰는 것이 **상호정보량**(mutual information, MI)과 상관비(correlation ratio)입니다. MI는 "한 영상의 밝기를 알면 다른 영상의 밝기를 얼마나 잘 맞힐 수 있나"를 재므로, 밝기의 순서가 뒤집혀 있어도 대응 관계만 일관되면 최대가 됩니다(예시 2).

변환 모형은 affine(12개 모수)에서 수천~수백만 모수의 **비선형 변형**까지 다양합니다. 모수가 많을수록 세부까지 맞지만, 제약 없이 두면 해부학적으로 말이 안 되는 뒤틀림이 생깁니다. 그래서 복잡한 변형일수록 벌점을 주는 **정규화 항**(regularization)과, 낮은 해상도에서 큰 구조부터 맞추고 점점 세밀하게 가는 **다중 해상도 최적화**를 씁니다. 매끄럽고 접힘이 없는 변형(diffeomorphism)을 쓰는 방법들(SPM의 DARTEL, FSL의 FNIRT, ANTs의 SyN 등)은 선형 정합보다 대체로 정확하다고 보고되었습니다. 겉질만 본다면 겉질 표면을 재구성해 고랑·이랑 모양으로 맞추는 **표면 기반 정합**(FreeSurfer 등)도 선택지이지만, 깊은 회색질 구조는 다루지 못합니다.

### 위축된 뇌, 병변 있는 뇌: 퇴행성 질환 연구의 핵심 주의점

노화와 알츠하이머병 같은 퇴행성 질환에서는 회백질이 줄고 뇌실과 고랑이 넓어지며, 사람 간 차이도 커집니다. 젊은 성인 평균으로 만든 템플릿에 위축된 뇌를 억지로 맞추면 정합 오차가 체계적으로 생기고, 그 오차가 **집단 차이와 같은 방향**으로 쌓여 "활성 차이"처럼 보일 수 있습니다. 대응책은 다음과 같습니다.

- QC를 더 엄격히 한다: 정규화된 뇌 위에 템플릿 윤곽을 겹쳐 보고, 모든 피험자의 정규화 결과를 평균했을 때 "흐릿하지만 뇌다운" 모양이 나오는지, 피험자들을 영화처럼 넘겨 볼 때 튀는 사람이 없는지 확인한다.
- 연구 집단에 맞춘 **맞춤 템플릿**을 만들 수 있다. 같은 촬영 조건의 영상으로 만들어야 하며, 그렇게 얻은 좌표가 표준 MNI 좌표와 그대로 같지는 않다는 점을 보고한다.
- 서로 비교할 집단(예: 환자와 대조군)에 **서로 다른 템플릿을 쓰지 않는다.** 템플릿 차이가 그대로 집단 차이가 된다.
- 뇌졸중·종양처럼 신호가 빈 병변은 그 부분을 비용 계산에서 빼는 **cost function masking**을 쓴다. 병변이 주변 구조를 밀어낸 경우에는 정규화 자체가 어려울 수 있어, 각자 공간에서 해부학적 ROI로 요약하는 쪽이 나을 수 있다.

이 문제는 질환 연구에서 특히 중요합니다. 위축이 심한 영역에서 BOLD 차이가 나왔다면 "기능 차이"인지 "정합·부분 용적 차이"인지를 먼저 의심하고, 회백질 양을 공변량으로 넣거나 개인 공간 ROI로 다시 확인하는 민감도 분석(Day 39)을 고려하세요.

### 결과의 위치를 말하는 법: 좌표, 아틀라스, Brodmann 영역

결과 표에는 보통 cluster마다 최고점의 좌표(x, y, z mm)와 해부학 이름을 적습니다. 원칙은 세 가지입니다. 첫째, **MNI 공간으로 정규화했다면 MNI 좌표로 보고**합니다. MNI를 Talairach로 바꾸는 표준 변환이 없어 오차만 더해지기 때문입니다. 둘째, 이름은 좌표 자동 조회보다 해부학 지식과 아틀라스를 함께 써서 붙입니다. 한 사람의 뇌로 만든 아틀라스보다 여러 사람의 변이를 담은 **확률 아틀라스**(예: FSL에 포함된 Harvard–Oxford)가 낫고, 자동 분할(FreeSurfer 등)도 결과를 눈으로 확인해야 합니다. 셋째, **Brodmann 영역** 이름은 겉모양 해부학에서 추측하지 말고, 사후 조직 검사로 만든 확률적 세포구축 지도가 있는 경우에만 씁니다. 큰 cluster는 최고점 셋만 적으면 포함된 구조를 빠뜨리므로, cluster가 걸친 영역을 아틀라스와 겹쳐 함께 적는 방법도 있습니다.

그림을 그릴 때 집단 결과는 한 사람의 선명한 뇌가 아니라 **그 집단의 평균 구조 영상** 위에 얹는 것이 정직합니다. 선명한 배경은 실제보다 높은 해부학적 정밀도를 암시하기 때문입니다(Day 5의 "정직한 그림" 원칙).

> **책 이후의 변화:** 정규화 도구는 ANTs, FSL, FreeSurfer를 조합한 파이프라인(fMRIPrep 등) 안에서 자동으로 실행되는 경우가 많아졌고, 여러 해상도·판본의 템플릿은 TemplateFlow 같은 저장소에서 버전과 함께 내려받아 씁니다. 보고 기준은 COBIDAS(Nichols 등 2017) 체크리스트로 정리되었습니다.

## 예시로 이해하기

> 모든 영상은 연습용으로 만든 **가상 그림**입니다.

### 예시 1 — 보간을 거듭하면 영상이 번진다, 라벨 영상은 nearest로

```python
import numpy as np
from scipy import ndimage

# 가상 '구조 영상' 한 장: 줄무늬가 있는 원 (세밀한 경계가 많은 그림)
yy, xx = np.mgrid[0:96, 0:96]
inside = (xx - 48) ** 2 + (yy - 48) ** 2 < 40 ** 2
img = ((xx // 6) % 2).astype(float) * inside

def roundtrip(order, n_steps):
    """30도 돌렸다가 다시 30도 되돌린다. n_steps번에 나눠 돌리면 그만큼 보간을 더 한다."""
    out = img.copy()
    for angle in [30 / n_steps] * n_steps + [-30 / n_steps] * n_steps:
        out = ndimage.rotate(out, angle, reshape=False, order=order)
    return np.sqrt(np.mean((out - img)[inside] ** 2))   # 원본과의 오차(RMSE)

print("보간 방식       2번 보간(합친 변환)  12번 보간(단계마다 저장)")
for order, name in [(0, "nearest"), (1, "linear"), (3, "cubic spline")]:
    print(f"{name:13} {roundtrip(order, 1):18.3f} {roundtrip(order, 6):20.3f}")

# 라벨 영상(아틀라스)은 값이 '이름표'다. 보간 방식에 따라 없는 라벨이 생긴다
labels = np.zeros((40, 40)); labels[5:20, 5:35] = 12; labels[20:35, 5:35] = 20   # 가상 구조 12번, 20번
for order in [0, 1]:
    moved = np.round(ndimage.rotate(labels, 10, reshape=False, order=order), 1)
    print("order=%d 뒤 라벨 값 종류: %d개, 예: %s" % (order, np.unique(moved).size, np.unique(moved)[:6]))
```

출력:

```text
보간 방식       2번 보간(합친 변환)  12번 보간(단계마다 저장)
nearest                    0.127                0.109
linear                     0.105                0.234
cubic spline               0.035                0.112
order=0 뒤 라벨 값 종류: 3개, 예: [ 0. 12. 20.]
order=1 뒤 라벨 값 종류: 60개, 예: [0.  0.4 0.6 0.7 0.8 1.1]
```

같은 30도 회전을 두 번(돌리고 되돌리기) 보간하느냐 열두 번 나눠 보간하느냐의 차이입니다. linear와 cubic spline은 보간 횟수가 늘수록 오차가 두세 배 커집니다. 이것이 "여러 변환을 합친 뒤 한 번에 적용하라"는 원칙의 근거입니다. nearest는 값을 섞지 않아 번지지는 않지만 영상이 계단처럼 깨져 오차가 처음부터 큽니다. 반대로 아틀라스 같은 **라벨 영상**에서는 nearest만 써야 합니다. linear로 보간하면 12번과 20번 구조의 경계에 16 같은 "존재하지 않는 구조 번호"가 생깁니다(출력의 60가지 값).

### 예시 2 — 대비가 뒤집힌 두 영상: 상관과 상호정보량

```python
import numpy as np

rng = np.random.default_rng(5)
yy, xx = np.mgrid[0:80, 0:80]
r = np.sqrt((xx - 40) ** 2 + (yy - 40) ** 2)
tissue = np.select([r < 12, r < 25, r < 34], [1, 2, 3], 0)   # 0 바깥, 1 '뇌실', 2 '백질', 3 '회백질'

# 같은 조직이 영상 종류에 따라 밝기 순서가 다르다 (가상 대비)
t1_like = np.choose(tissue, [0, 20, 100, 60]) + rng.normal(0, 5, tissue.shape)
t2_like = np.choose(tissue, [0, 100, 30, 60]) + rng.normal(0, 5, tissue.shape)

def mutual_info(a, b, bins=32):
    p, _, _ = np.histogram2d(a.ravel(), b.ravel(), bins=bins)
    p = p / p.sum()
    pa, pb = p.sum(1, keepdims=True), p.sum(0, keepdims=True)
    nz = p > 0
    return float((p[nz] * np.log(p[nz] / (pa @ pb)[nz])).sum())

head = r < 34                                   # 머리 안쪽만 비교한다
print("이동(voxel)  상관계수   상호정보량(MI)")
for shift in [0, 2, 5, 10]:
    moved = np.roll(t2_like, shift, axis=1)
    a, b = t1_like[head], moved[head]
    print(f"{shift:>8}   {np.corrcoef(a, b)[0, 1]:8.3f}   {mutual_info(a, b):10.3f}")
```

출력:

```text
이동(voxel)  상관계수   상호정보량(MI)
       0     -0.954        1.001
       2     -0.689        0.736
       5     -0.372        0.503
      10      0.043        0.342
```

두 가상 영상은 같은 조직 배치를 갖지만 밝기 순서가 다릅니다. 정확히 맞았을 때(이동 0) 상관은 −0.95로 **가장 나쁜** 값이고, 어긋날수록 0에 가까워집니다. 상관을 최대화하는 비용 함수를 쓰면 정합기가 일부러 영상을 어긋나게 만들 것입니다. 상호정보량은 정확히 맞았을 때 가장 크고 어긋날수록 줄어듭니다. 이 때문에 기능 영상(T2*)과 구조 영상(T1)의 정합에는 MI나 상관비 같은 비용 함수를 씁니다.

## 직접 해보기

1. `D3_normalization_atlas.ipynb`에서 예시 1–2를 실행한다.
2. 예시 1의 회전 각을 30도에서 5도로 줄이고, 보간 횟수에 따른 오차 차이가 여전히 나타나는지 확인한다.
3. 예시 2에서 잡음 표준편차를 5에서 20으로 키우면 MI 곡선이 어떻게 변하는지 보고, 잡음이 많은 영상일수록 정합이 어려운 이유를 적는다.
4. `reports/advanced/D3_normalization_qc_plan.md`를 만들고, "60–80대 환자군과 대조군의 fMRI를 정규화한다면" 다음 다섯 줄을 채운다: 쓸 템플릿과 그 이유 / 두 집단에 같은 템플릿을 쓰는지 / 정규화 QC 세 가지 / 위축이 결과에 섞였는지 확인할 민감도 분석 하나 / 결과 표에 적을 좌표 공간과 아틀라스 이름.
5. 아무 fMRI 논문 하나의 방법 절에서 "정규화에 쓴 도구, 템플릿 판, 선형/비선형 여부, 보고 좌표 공간"이 모두 적혀 있는지 확인하고, 빠진 항목을 적는다.

⚠️ **흔한 오류 1 — 뇌 추출한 영상을 두개골이 있는 템플릿에 맞추기(또는 그 반대).** 겉질 표면이 템플릿의 두피에 맞춰지는 큰 실패가 납니다. 영상과 템플릿의 처리 상태(뇌 추출 여부)를 맞추세요. 형식 변환 뒤 축 방향이 뒤바뀐 경우도 흔하므로, 세 방향 단면을 나란히 띄워 템플릿과 같은 방향인지 먼저 확인합니다.

⚠️ **흔한 오류 2 — 좌표를 Talairach로 바꿔 보고하거나 공간 이름을 생략하기.** "Talairach 좌표"라는 말을 표준 공간 일반의 뜻으로 쓰는 습관이 남아 있어 혼란이 큽니다. 실제로 맞춘 템플릿의 이름과 판을 그대로 적으세요.

## 퀴즈

**1.** 기능 영상을 템플릿으로 옮길 때 여러 변환을 하나로 합쳐 한 번만 보간하는 이유는?

<details><summary>정답 보기</summary>

보간할 때마다 영상이 조금씩 번지고 오차가 쌓이기 때문입니다. 예시 1에서 linear 보간은 열두 번 보간했을 때 오차가 두 배 이상 커졌습니다. 변환 행렬(과 변형장)은 합칠 수 있으므로, 영상은 마지막에 한 번만 다시 그립니다.

</details>

**2.** T2* 기능 영상과 T1 구조 영상의 정합에 알맞은 비용 함수는?

(a) 밝기 차이의 제곱합 (b) 정규화 상관 (c) 상호정보량 또는 상관비 (d) 아무것이나 같다

<details><summary>정답 보기</summary>

(c). 대비가 다른 영상은 같은 조직의 밝기가 다르므로 (a)·(b)는 잘못된 위치를 최적으로 판단할 수 있습니다. 상호정보량과 상관비는 밝기 사이의 일관된 대응 관계만 요구합니다.

</details>

**3.** 아틀라스 라벨 영상을 다른 공간으로 옮길 때 써야 하는 보간은? (단답)

<details><summary>정답 보기</summary>

nearest neighbor입니다. 라벨 값은 크기가 아니라 이름표라서, 평균을 내는 보간을 쓰면 경계에 존재하지 않는 라벨 번호가 생깁니다.

</details>

**4.** 알츠하이머병 환자와 대조군을 비교하면서 각 집단에 맞춘 템플릿을 따로 만들어 정규화했습니다. 무엇이 문제인가요?

<details><summary>정답 보기</summary>

두 템플릿 사이의 차이가 체계적인 정합 차이를 만들고, 그것이 그대로 집단 차이처럼 보일 수 있습니다. 비교할 집단은 같은 템플릿(필요하면 두 집단을 모두 포함한 맞춤 템플릿)으로 정규화하고, 위축이 결과에 섞였는지 따로 점검합니다.

</details>

**5.** 집단 활성 지도를 한 사람의 고해상도 구조 영상 위에 그리면 생기는 문제는?

(a) 색이 바랜다 (b) 실제보다 높은 해부학적 정밀도를 암시한다 (c) 좌우가 바뀐다 (d) 통계값이 달라진다

<details><summary>정답 보기</summary>

(b). 집단 결과에는 사람 간 해부학 변이와 smoothing이 섞여 있습니다. 그 집단의 평균 구조 영상 위에 그리면 흐릿하지만 결과의 실제 정밀도를 정직하게 보여 줍니다.

</details>
