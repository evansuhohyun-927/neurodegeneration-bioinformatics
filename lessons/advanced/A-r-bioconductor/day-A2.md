## 개념 설명

### 벡터는 한 종류의 값만 담는 시험관 꽂이다

R에서 가장 기본이 되는 자료 구조는 **원자 벡터(atomic vector)** 입니다. 같은 종류의 값이 순서대로 꽂힌 시험관 꽂이라고 생각하면 됩니다. 종류는 주로 네 가지입니다: 논리(`logical`, TRUE/FALSE), 정수(`integer`), 실수(`double`), 문자(`character`). 숫자 하나, 문자열 하나도 길이 1인 벡터입니다. 그래서 R에는 "스칼라"라는 별도 자료형이 없습니다.

한 꽂이에는 한 종류만 꽂을 수 있으므로, 서로 다른 종류를 `c()`로 섞으면 R이 **조용히 한 종류로 맞춥니다**. 이것을 **강제 변환(coercion)** 이라고 합니다. 순서는 논리 → 정수 → 실수 → 문자로, 더 넓은 쪽으로 끌려갑니다. 숫자 열에 글자 하나("n/a")가 섞여 있으면 열 전체가 문자로 읽히는 이유가 이것입니다. 엑셀에서 받은 표의 숫자 열이 `chr`로 보이면 이 규칙을 의심하세요.

`typeof()`는 저장 방식을, `class()`는 그 객체가 어떤 "종류"로 대접받는지를 알려 줍니다. 단순한 숫자 벡터는 둘이 거의 같지만, Day A3의 factor나 data.frame부터는 달라지고, Day A6에서는 이 `class`가 함수의 행동을 바꾸는 열쇠가 됩니다.

### NA, NULL, 그리고 부동소수점

**`NA`** 는 "값이 있어야 할 자리인데 모른다"는 뜻입니다. 측정 실패한 웰을 빈칸으로 두는 것과 같습니다. 모르는 값이 섞인 계산의 결과도 모르는 것이므로 `mean(c(1, NA))`는 `NA`입니다. 결측을 빼고 계산하려면 `na.rm = TRUE`를 명시해야 합니다. 귀찮아 보이지만, 결측이 있다는 사실을 분석자가 반드시 알아차리게 만드는 안전장치입니다. 결측 여부는 `x == NA`가 아니라 `is.na(x)`로 확인합니다(`NA`와의 비교 결과도 `NA`이므로).

**`NULL`** 은 "아예 없음"입니다. 길이가 0이고 `c(1, NULL)`에 넣으면 사라집니다. 빈칸(`NA`)과 칸 자체가 없는 것(`NULL`)의 차이입니다.

컴퓨터는 0.1 같은 소수를 2진수로 정확히 저장하지 못합니다. 그래서 `0.1 + 0.2 == 0.3`이 FALSE가 됩니다. Python도 같습니다. 실수끼리 같은지 볼 때는 `all.equal()`처럼 허용 오차를 두는 비교를 씁니다.

### 벡터 연산과 재활용 규칙

R의 산술 연산과 많은 함수는 **벡터 전체에 한 번에** 작용합니다. 대조군과 처리군 count 벡터가 있으면 `log2((treat + 1) / (ctrl + 1))` 한 줄이 유전자마다 fold change를 계산합니다. 반복문을 쓸 수도 있지만, 벡터 연산이 더 짧고, 읽기 쉽고, 대개 훨씬 빠릅니다(Day A4에서 시간을 재 봅니다).

길이가 다른 두 벡터를 연산하면 짧은 쪽을 처음부터 되풀이해 길이를 맞춥니다. 이것이 **재활용 규칙(recycling rule)** 입니다. `x * 2`가 되는 것도 길이 1짜리 `2`가 재활용된 결과입니다. 문제는 긴 쪽이 짧은 쪽의 배수가 아닐 때입니다. R은 경고만 내고 계산을 끝냅니다. 샘플 6개짜리 벡터에 정규화 계수 5개를 곱하는 실수를 해도 결과가 나온다는 뜻이니, 경고 메시지를 절대 무시하지 마세요.

### 부분 선택: 네 가지 열쇠

대괄호 `[ ]` 안에 넣을 수 있는 "열쇠"는 네 종류이고, 한 번에 한 종류만 씁니다.

1. **양수 위치**: `x[c(1, 3)]` — 1번째와 3번째.
2. **음수 위치**: `x[-2]` — 2번째를 뺀 나머지.
3. **논리 벡터**: `x[x > 1]` — 조건이 TRUE인 자리만. 실전에서 가장 많이 씁니다.
4. **이름**: `x[c("Gfap", "Cd68")]` — 이름표로 고르기. 순서가 바뀌어도 안전합니다.

`%in%`은 "이 값이 저 목록 안에 있나"를 원소마다 묻는 연산자입니다. 관심 유전자 목록으로 결과 표를 거를 때 씁니다. `which()`는 TRUE인 위치 번호를 알려 줍니다. 대괄호는 값을 꺼낼 때뿐 아니라 **바꿀 때**도 씁니다: `x[x < 0] <- 0`은 음수를 모두 0으로 바꿉니다.

### 문자열도 벡터다

R의 문자 벡터는 "글자의 나열"이 아니라 "문자열의 나열"입니다. `"Gfap"`은 길이 1인 문자 벡터이고, 글자 수는 `nchar()`로 셉니다. 문자열 함수도 대부분 벡터 전체에 작용합니다: `grepl()`(패턴이 있나), `sub()`/`gsub()`(바꾸기), `toupper()`/`tolower()`, `paste()`/`sprintf()`(이어 붙이기·서식), `strsplit()`(쪼개기). 패턴에는 **정규 표현식(regular expression)** 을 씁니다. `^`는 시작, `$`는 끝, `[0-9]+`는 숫자 한 개 이상입니다. 프로브 ID에서 유전자 기호만 떼어 내거나, 음성 대조 프로브를 골라낼 때 바로 쓰입니다.

### 예시 1 — 자료형, 강제 변환, 결측

```r
mixed <- c(1, "Gfap", TRUE)
mixed

0.1 + 0.2 == 0.3

```


숫자 1과 TRUE가 문자열 `"1"`, `"TRUE"`로 바뀌었습니다. `"n/a"`를 숫자로 바꾸면 `NA`가 되고 경고가 붙습니다. 이 경고는 "원래 데이터에 숫자가 아닌 칸이 있었다"는 신호이니, 어떤 칸이었는지 찾아보는 계기로 삼으세요. `sum(is.na(expr))`처럼 논리 벡터를 더하면 TRUE의 개수가 나옵니다.

### 예시 2 — 벡터 연산과 재활용

```r
ctrl  <- c(Gfap = 400, Aif1 = 210, Cd68 = 50, Tmem119 = 300)
treat <- c(Gfap = 900, Aif1 = 400, Cd68 = 210, Tmem119 = 290)
log2fc <- log2((treat + 1) / (ctrl + 1))
round(log2fc, 2)
1:6 + c(0, 100)          # 짧은 쪽이 되풀이된다(recycling)
1:5 + c(0, 100)          # 길이가 배수가 아니면 경고
```

출력:

```text
   Gfap    Aif1    Cd68 Tmem119 
   1.17    0.93    2.05   -0.05 
[1]   1 102   3 104   5 106
[1]   1 102   3 104   5
Warning message:
In 1:5 + c(0, 100) :
  longer object length is not a multiple of shorter object length
```

fold change 계산에 반복문이 하나도 없습니다. 이름표도 그대로 따라옵니다. 아래 두 줄은 `c(0, 100)`이 `0, 100, 0, 100, ...`으로 되풀이되는 모습입니다. 길이 5와 2처럼 나누어떨어지지 않으면 결과는 나오지만 경고가 붙습니다.

### 예시 3 — 네 가지 열쇠와 `%in%`

```r
lfc <- c(Gfap = 1.17, Aif1 = 0.93, Cd68 = 2.05, Tmem119 = -0.05, Il1b = 1.60)
lfc[c(1, 3)]                 # 양수 위치
lfc[-c(1, 3)]                # 음수 위치 = 빼기
lfc[lfc > 1]                 # 논리 벡터
lfc[c("Cd68", "Gfap")]       # 이름
which(lfc > 1)
microglia <- c("Aif1", "Tmem119", "P2ry12")
microglia %in% names(lfc)
lfc[names(lfc) %in% microglia]
lfc[lfc > 1] <- round(lfc[lfc > 1])   # 부분 대입
lfc
```

출력:

```text
Gfap Cd68 
1.17 2.05 
   Aif1 Tmem119    Il1b 
   0.93   -0.05    1.60 
Gfap Cd68 Il1b 
1.17 2.05 1.60 
Cd68 Gfap 
2.05 1.17 
Gfap Cd68 Il1b 
   1    3    5 
[1]  TRUE  TRUE FALSE
   Aif1 Tmem119 
   0.93   -0.05 
   Gfap    Aif1    Cd68 Tmem119    Il1b 
   1.00    0.93    2.00   -0.05    2.00 
```

`microglia %in% names(lfc)`의 세 번째가 FALSE인 것은 `P2ry12`가 결과 표에 없다는 뜻입니다. 3주차에 배운 것처럼 패널 데이터에서는 "관심 유전자가 애초에 측정 대상이 아니었다"는 경우가 흔하니, 고르기 전에 이렇게 먼저 확인합니다. 마지막 부분 대입은 원래 벡터 `lfc`를 직접 바꿉니다.

### 예시 4 — 프로브 이름 다듬기와 서열 문자열

```r
ids <- c("Gfap_probe001", "Aif1_probe002", "NEG_C_probe003")
nchar(ids)
grepl("^NEG", ids)
sub("_probe[0-9]+$", "", ids)
tolower("GFAP")
sprintf("%s: log2FC = %.2f", "Cd68", 2.0456)
revcomp <- function(s) paste(rev(strsplit(chartr("ACGT", "TGCA", s), "")[[1]]), collapse = "")
revcomp("ATGCCGTA")
```

출력:

```text
[1] 13 13 14
[1] FALSE FALSE  TRUE
[1] "Gfap"  "Aif1"  "NEG_C"
[1] "gfap"
[1] "Cd68: log2FC = 2.05"
[1] "TACGGCAT"
```

`grepl("^NEG", ids)`는 "NEG로 시작하는가"를 원소마다 묻습니다. `sub()`는 끝의 `_probe` + 숫자를 지웁니다. 마지막 줄은 [보충 S1](../../supplement/day-S1.md)에서 Python으로 해 본 역상보 서열을 R로 옮긴 것입니다: `chartr`로 염기를 짝으로 바꾸고, 한 글자씩 쪼개 뒤집은 뒤 다시 붙입니다. 실제 서열 분석에는 Bioconductor의 Biostrings 패키지가 이런 작업을 대신 해 줍니다(Day A6).

**2.** `mean(c(4, NA, 8))`의 결과와, 6을 얻으려면 어떻게 해야 하는지 쓰세요. (단답)

</details>

**3.** `x <- c(a = 1, b = -2, c = 3)`에서 같은 결과(`a`와 `c`)를 주지 **않는** 것은?

(a) `x[c(1, 3)]` (b) `x[-2]` (c) `x[x > 0]` (d) `x[c(TRUE, FALSE)]` (e) `x[c("a", "b")]`

(e). 이름으로 `a`와 `b`를 골랐으니 결과가 다릅니다. (d)는 길이 2인 논리 벡터가 재활용되어 `TRUE, FALSE, TRUE`가 되므로 `a`와 `c`가 나옵니다. 의도치 않은 재활용이 이렇게도 일어납니다.

</details>

**4.** 길이 6인 벡터와 길이 4인 벡터를 더하면?

(a) 오류로 멈춘다 (b) 경고와 함께 길이 6인 결과가 나온다 (c) 길이 4인 결과가 나온다 (d) 길이 24인 결과가 나온다

<details><summary>정답 보기</summary>

(b). 짧은 쪽을 되풀이해 길이를 맞추고, 6이 4의 배수가 아니므로 경고만 냅니다. 결과가 나온다는 것이 위험한 점입니다.

</details>

**5.** 결과 표의 유전자 이름 벡터 `g`에서 관심 목록 `targets`에 들어 있는 것만 고르는 식을 쓰세요. (단답)

<details><summary>정답 보기</summary>

`g[g %in% targets]`입니다. `%in%`은 `g`의 원소마다 `targets` 안에 있는지 TRUE/FALSE로 답하고, 그 논리 벡터로 고릅니다. 반대로 `targets %in% g`는 관심 유전자 중 측정된 것이 무엇인지 확인할 때 씁니다.
