- EHR(전자건강기록) 데이터가 연구용이 아니라 진료·청구용으로 만들어졌다는 점이 분석에 어떤 흔적을 남기는지 예를 들어 설명할 수 있다.
- 막연한 임상 질문을 대상·노출·비교·결과·시점 다섯 칸으로 쪼개 연구 질문 한 문장으로 쓸 수 있다.
- 내 질문이 기술(서술)·비교 효과·예측 중 어느 종류인지 구분하고, 그에 맞는 데이터베이스의 조건을 말할 수 있다.

## 개념 설명

### 1차 사용과 2차 사용: 진료 기록은 연구 노트가 아니다

병원 기록의 **1차 사용(primary use)** 은 눈앞의 환자를 돌보고, 다음 근무자에게 인계하고, 보험 청구를 하는 것입니다. 그 기록을 모아 나중에 연구 질문에 답하는 것이 **2차 사용(secondary use)** 입니다. 실험실 비유로 말하면, EHR은 내가 설계한 실험 노트가 아니라 다른 연구실이 다른 목적으로 남긴 노트를 빌려 읽는 일입니다. 쓰여 있는 것은 많지만, 내가 궁금한 것이 그 목적으로 기록되지는 않았습니다.

이 차이가 분석에 남기는 흔적은 구체적입니다. 첫째, **측정은 필요할 때만** 합니다. 젖산(lactate)은 의사가 걱정될 때 재기 때문에 "젖산 값이 있다"는 사실 자체가 중증도의 신호입니다. 둘째, **진단 코드는 청구 규칙을 따릅니다.** 검사를 정당화하려고 붙인 코드가 진단이 배제된 뒤에도 남아 있을 수 있습니다. 셋째, **시간 기록에 여러 종류가 있습니다.** 채혈 시각, 결과가 전산에 올라온 시각, 간호사가 입력한 시각이 다릅니다. 넷째, **환자는 이미 병원에 온 사람들**입니다. 병원 데이터의 "건강한 대조군"은 일반 인구가 아닙니다.

그래서 EHR 2차 분석의 장점(크고, 실제 진료를 그대로 담고, 무작위 배정 시험이 다루기 어려운 환자까지 포함)과 약점(측정이 선택적이고, 교란이 깊다)은 같은 뿌리에서 나옵니다.

### 질문을 다섯 칸으로 쪼개기

"승압제를 일찍 쓰면 좋은가?" 같은 임상 질문은 그대로는 분석할 수 없습니다. 같은 문장이 수십 가지 연구로 갈라지기 때문입니다. 질문을 다섯 칸에 나눠 적으면 모호한 부분이 드러납니다.

| 칸 | 묻는 것 | 흔한 함정 |
|---|---|---|
| 대상 (population) | 누구를 넣는가. 나이, 질환, 병동, 몇 번째 입원 | 너무 넓으면 교란이 커지고, 너무 좁으면 일반화가 안 된다 |
| 노출 (exposure) | 무엇을 받았는가/가졌는가. 어떻게 기록에서 찾는가 | 코드로 찾을지 투약 기록으로 찾을지에 따라 다른 사람들이 잡힌다 |
| 비교 (comparison) | 노출되지 않은 누구와 견주는가 | 비교군이 애초에 덜 아픈 사람들이면 비교가 기울어진다 |
| 결과 (outcome) | 무엇을 재는가. 사망, 재원 기간, 검사 횟수 | 결과를 보고 나서 정의를 바꾸면 우연을 발견으로 착각한다 |
| 시점 (time) | 추적은 언제 시작하고(index time), 언제 끝나는가 | 시작점이 노출보다 앞서면 "불멸 시간"이 생긴다 (Day E3) |

임상의학의 PICO와 거의 같은 틀인데, EHR에서는 마지막 **시점** 칸이 특히 중요합니다. 기록이 시간 순으로 쌓이기 때문에 "언제부터 셀 것인가"를 정하지 않으면 노출과 결과의 순서가 뒤엉킵니다.

### 질문의 종류와 데이터베이스 고르기

같은 데이터로도 질문의 종류가 다르면 분석이 완전히 달라집니다(Day 29에서 설명과 예측을 구분한 것과 같은 이야기입니다).

- **기술·추세 질문:** "지난 10년 동안 이 처치의 사용률은 어떻게 변했나?" 시간이 주된 축입니다. 건수와 비율을 함께 봐야 합니다(예시 2).
- **비교 효과 질문(comparative effectiveness):** "A 치료를 받은 환자는 받지 않은 비슷한 환자보다 결과가 다른가?" 무작위 배정이 없으므로 교란 통제(Day E5)가 핵심입니다.
- **예측 질문:** "입실 24시간의 정보로 사망 위험을 얼마나 잘 맞히나?" 인과가 아니라 처음 보는 환자에게서의 성능이 핵심입니다(Day E6).
- **약물 감시(pharmacovigilance):** 시판 후 드문 부작용 신호를 찾는 일. 시험에서는 너무 드물어 안 보이던 사건을 큰 기록에서 찾습니다.

데이터베이스도 질문에 맞춰 고릅니다. 보험 청구 자료는 인구 대표성이 좋지만 검사값·활력징후·정확한 시각이 거의 없어 중증도를 보정하기 어렵습니다. 질환 등록부(registry)는 특정 질환에 깊지만 미리 정한 변수만 있습니다. 중환자실 EHR 데이터베이스는 시간 단위의 촘촘한 생리 기록이 있어 중증도를 잴 수 있는 대신, 한 기관(또는 몇 기관)의 환자라는 한계가 있습니다. "이 데이터에 내 교란변수가 측정되어 있는가?"가 고르는 기준입니다.

### 무작위 배정 시험과 관찰 연구: 누가 더 낫다가 아니라 무엇을 할 수 있나

무작위 배정 시험(RCT)은 동전 던지기로 치료를 나누므로, 측정한 것과 측정하지 못한 것 모두가 평균적으로 두 군에 고르게 퍼집니다. 그래서 인과 주장의 기준이 됩니다. 하지만 비싸고 느리며, 고령·다질환·임신부처럼 실제 진료에서 흔한 환자를 자주 제외합니다. 관찰 연구는 그 빈자리를 채우지만, 치료를 "누가 왜 받았는가"가 결과와 얽혀 있다는 근본 문제를 안고 갑니다. 이 과정의 해석 원칙대로, EHR 한 편의 결과는 **연관과 가설**이며 인과 결론은 여러 연구와 기전 근거가 쌓여야 합니다.

## 예시로 이해하기

### 예시 1 — 다섯 칸 질문표를 코드로 만들어 두기

질문을 dict로 적어 두면 나중에 코호트 코드를 짤 때 그대로 참고할 수 있고, 빈칸이 있으면 바로 보입니다.

```python
question = {
    "대상": "18세 이상, 첫 ICU 입실, 입실 6시간 안에 저혈압(MAP < 65)이 있었던 환자",
    "노출": "저혈압 발생 후 3시간 안에 승압제 시작",
    "비교": "같은 조건에서 3시간 안에 승압제를 시작하지 않은 환자",
    "결과": "ICU 입실 후 28일 사망",
    "시점": "",          # 아직 정하지 못함
}
missing = [k for k, v in question.items() if not v]
print("빈칸:", missing)
print(f"대상: {question['대상']}")
print(f"질문: [{question['노출']}]은 [{question['비교']}]에 비해 "
      f"[{question['결과']}]과 어떤 연관이 있는가?")
```

출력:

```text
빈칸: ['시점']
대상: 18세 이상, 첫 ICU 입실, 입실 6시간 안에 저혈압(MAP < 65)이 있었던 환자
질문: [저혈압 발생 후 3시간 안에 승압제 시작]은 [같은 조건에서 3시간 안에 승압제를 시작하지 않은 환자]에 비해 [ICU 입실 후 28일 사망]과 어떤 연관이 있는가?
```

"시점"이 비어 있다는 것은 "추적을 저혈압 발생 시각부터 셀지, ICU 입실부터 셀지"를 정하지 않았다는 뜻입니다. Day E3에서 이 빈칸을 채우지 않으면 어떤 편향이 생기는지 직접 봅니다. 대괄호는 칸의 경계를 눈으로 확인하려고 넣은 것이니, 보고서에서는 문장을 손으로 다듬으세요.

### 예시 2 — 건수는 늘었는데 비율은 줄었다

가상 병원에서 어떤 장치를 쓴 환자 수를 해마다 세어 봅니다.

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(1)
rows = []
for year in range(2015, 2021):
    n_adm = 800 + 120 * (year - 2015)            # 해마다 입원 환자가 늘어난다
    p_use = 0.30 - 0.02 * (year - 2015)          # 장치를 쓰는 '비율'은 줄어든다
    used = rng.random(n_adm) < p_use
    rows.append({"year": year, "admissions": n_adm, "device_used": used.sum()})
trend = pd.DataFrame(rows)
trend["rate_%"] = (100 * trend["device_used"] / trend["admissions"]).round(1)
print(trend.to_string(index=False))
```

출력:

```text
 year  admissions  device_used  rate_%
 2015         800          242    30.2
 2016         920          257    27.9
 2017        1040          277    26.6
 2018        1160          287    24.7
 2019        1280          277    21.6
 2020        1400          254    18.1
```

장치를 쓴 **건수**만 보면 2018년까지 늘었으니 "사용이 늘고 있다"고 쓰기 쉽습니다. 그러나 분모(입원 수)가 더 빨리 늘었기 때문에 **비율**은 매년 줄었습니다. 추세 질문에서는 분자와 분모를 함께 보여 주는 것이 기본입니다. 실제 분석이라면 해마다 환자 구성(나이, 중증도)이 달라졌는지도 확인해야 합니다.

### 예시 3 — "검사를 많이 했다"는 것 자체가 신호다

기록에는 없는 "실제 중증도"가 검사 횟수와 사망을 동시에 움직이는 가상 상황입니다.

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(7)
n = 2000
severity = rng.normal(0, 1, n)                     # 기록에는 없는 '실제 중증도'
n_labs = rng.poisson(np.exp(1.5 + 0.6 * severity)) # 아픈 환자일수록 검사를 자주 한다
p_death = 1 / (1 + np.exp(-(-2.5 + 1.2 * severity)))
died = rng.random(n) < p_death
df = pd.DataFrame({"n_labs": n_labs, "died": died})
df["lab_group"] = pd.qcut(df["n_labs"], 4, labels=["Q1(적음)", "Q2", "Q3", "Q4(많음)"])
print(df.groupby("lab_group", observed=True)["died"].agg(["count", "mean"]).round(3))
```

출력:

```text
           count   mean
lab_group              
Q1(적음)       532  0.038
Q2           525  0.051
Q3           509  0.096
Q4(많음)       434  0.251
```

검사를 가장 많이 받은 사분위의 사망률이 가장 적게 받은 사분위의 여섯 배쯤입니다. 그렇다고 "검사가 사망을 일으킨다"고 읽으면 안 됩니다. 의사가 걱정되는 환자를 더 자주 검사한 흔적일 뿐입니다. 이것이 EHR의 **정보가 있는 결측·정보가 있는 측정(informative presence)** 입니다. 예측 모델에서는 이 신호가 성능을 올려 주기도 하지만, 그 모델은 "환자 상태"가 아니라 "의료진의 걱정"을 배운 것일 수 있습니다(Day E4, E6에서 다시 다룹니다).

④. 큰 표본에서 작은 차이도 유의해지는 것은 데이터의 출처와 무관한 통계의 일반적 성질입니다(Day 9). ①–③은 기록이 연구 목적이 아니라 진료와 청구 목적으로 만들어졌기 때문에 생기는 흔적입니다.

</details>

**2.** (단답) 예시 2에서 장치 사용 "건수"는 2018년까지 늘었는데 "비율"은 계속 줄었습니다. 이유를 한 문장으로 쓰세요.

<details><summary>정답 보기</summary>

분모인 입원 환자 수가 분자보다 빨리 늘었기 때문입니다. 추세를 말할 때는 건수와 비율(분자와 분모)을 함께 보고, 가능하면 환자 구성 변화도 확인합니다.

</details>

**3.** (객관식) "입실 24시간 정보로 ICU 사망 위험을 얼마나 잘 맞히는가"는 어떤 종류의 질문인가요?
① 기술·추세 ② 비교 효과 ③ 예측 ④ 약물 감시

<details><summary>정답 보기</summary>

③ 예측. 목표는 처음 보는 환자에게서 위험을 잘 맞히는 것이고, 각 변수의 인과 효과를 추정하는 것이 아닙니다. 그래서 평가도 효과 추정의 신뢰구간이 아니라 판별·보정·외부 검증으로 합니다(Day E6).

</details>

**4.** (단답) 예시 3에서 검사 횟수가 많은 환자의 사망률이 높았습니다. "검사가 해롭다"고 해석하면 안 되는 이유는?

<details><summary>정답 보기</summary>

기록되지 않은 중증도가 검사 횟수와 사망을 동시에 높이기 때문입니다. 의료진은 아픈 환자를 더 자주 검사합니다. 검사 횟수는 원인이 아니라 중증도의 흔적입니다.

</details>

**5.** (객관식) 무작위 배정 시험(RCT)과 비교해 EHR 관찰 연구의 장점으로 가장 알맞은 것은?
① 측정하지 않은 교란변수도 자동으로 균형이 맞는다
② 실제 진료에서 흔하지만 시험에서 자주 제외되는 환자까지 포함한다
③ 한 편의 결과로 인과를 확정할 수 있다
④ 결측이 없다

<details><summary>정답 보기</summary>

②. ①은 무작위 배정의 장점이고, ③은 관찰 연구가 할 수 없는 일이며, ④는 EHR과 정반대입니다. EHR은 대표성과 규모에서 강하고, 교란과 측정 선택성에서 약합니다.

</details>
