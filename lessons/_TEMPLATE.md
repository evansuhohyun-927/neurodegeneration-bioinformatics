# 레슨 작성 규칙 (모든 레슨 공통)

**학습자:** 생물학/의학 배경은 있음. Python·통계·터미널은 거의 처음. 한국어 사용자.
**하루 분량:** 75–90분. 레슨 하나 = 하루.
**톤:** Khan Academy처럼. 친절한 줄글, 일상·생물학 비유, 작은 예시를 여러 개. 전문용어는 처음 나올 때 한국어 풀이 + 영어 원어 병기.
생물학 개념은 길게 설명하지 말고(이미 앎), 코드·통계·데이터 개념을 생물학 비유로 풀어준다.

## 파일 위치와 이름

- 0주차: `lessons/week-0/day-F1.md` … `day-F7.md`
- 1–6주차: `lessons/week-N/day-01.md` … `day-42.md` (두 자리 숫자)

## 레슨 구조 (이 순서, 이 제목 그대로)

```markdown
# Day N — <제목>

> **주차:** N주차 · **예상 시간:** 75–90분 · **산출물:** <파일명>

## 오늘의 목표
- 3개 이내, "~할 수 있다" 형태

## 🎬 영상으로 먼저 보기
1–2개. 각 영상마다:
- [영상 제목 — 채널명](URL) (길이)
- **무엇에 주목할까:** 2–3문장 (한국어)

## 개념 설명
줄글 400–700자 × 2–4개 소단원(###). 비유 최소 1개.

## 예시로 이해하기
### 예시 1 / 예시 2 / (예시 3)
작은 구체적 예시. 코드가 있으면 실행 가능한 완전한 코드 + 예상 출력.

번호 매긴 실습 단계. 실라부스의 "실습" 칸을 따라 할 수 있게 풀어 쓴다.
막히기 쉬운 지점에 "⚠️ 흔한 오류" 1–2개.
```

## 반드시 지킬 것

1. **영상 링크는 실재해야 한다.** 영어 영상 우선(StatQuest, Khan Academy, Corey Schafer, freeCodeCamp, MIT OCW, 3Blue1Brown, iBiology, Data School 등). 모든 YouTube 링크는 아래로 확인하고, 확인된 제목을 그대로 쓴다:
   `curl -s "https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=<ID>&format=json"`
   확인이 안 되면 지어내지 말고 YouTube 검색 링크로 대체: `https://www.youtube.com/results?search_query=...` ("검색 링크"라고 표시).
2. **데이터셋 사실을 지어내지 않는다.** OSD-536, PADS 등의 파일명·표본 수·열 이름은 실제 페이지에서 확인한 것만 쓴다. 확인 못 한 것은 "study record에서 직접 확인하세요"라고 쓰고 확인 방법을 안내한다.
3. **코드는 초보자가 그대로 붙여 넣어 돌아가야 한다.** 실제 데이터가 필요 없는 예시는 코드 안에서 작은 가상 데이터를 만든다. `python3`에 필요한 라이브러리가 이미 있으면 실행해서 출력을 확인한다(아무것도 설치하지 말 것). 실행 못 한 코드의 출력은 "예상 출력"으로 표시.
4. **실라부스의 해석 원칙을 유지한다:** 마우스 분자 데이터와 인간 운동 데이터를 직접 결합하거나 인과로 연결하지 않는다. 작은 표본은 가설 생성. 참가자 단위 split. 진단·치료 주장 금지.
6. **공개 저장소용 저작권 규칙:** 영상·웹페이지·논문은 링크와 제목만 쓴다. 자막·본문·교과서 문장을 옮겨 적지 않고(설명은 자기 말로), 외부 이미지·썸네일을 넣지 않는다(`![](http...)` 금지). 그림은 레슨의 코드로 직접 생성한다. 데이터 파일과 `/Users/...` 같은 개인 절대 경로를 넣지 않는다.
5. 이 폴더의 다른 주차 파일은 건드리지 않는다. 자기 주차의 7개 파일만 만든다.
